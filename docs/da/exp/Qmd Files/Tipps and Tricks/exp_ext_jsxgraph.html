JSXGraph – interaktive grafer

Your answers are saved only in this browser.

Installation: er en del af CTM Assessment, se Oversigt og installation Kilde: (Miller 2023), github.com/jsxgraph/jsxgraph-quarto

JSXGraph-versionen i CTM Assessment bygger på udvidelsen jsxgraph-quarto og tilføjer en bedømmelsesbro: en graf kan levere svaret på en math-exercise-opgave. JSXGraph-biblioteket hentes fra nettet, når siden læses, og pakken bestemmer, hvilken version der bruges.

side.qmd
engine: markdown      # kun nødvendigt, hvis siden også indeholder math-exercise (Quarto 1.10+)
filters:
  - ctm-assessment
AdvarselInstallér ikke JSXGraph en gang til

JSXGraph følger med ctm-assessment og ligger i _extensions/jsxgraph/. Et ekstra quarto add jsxgraph/jsxgraph-quarto havner indlejret i _extensions/jsxgraph/jsxgraph/ og bliver ignoreret. Bygningen udskriver en advarsel om det. Står et enkeltfilter som jsxgraph i sidehovedet, erstatter ctm-assessment det: en side angiver enten ctm-assessment eller enkelte komponenter, ikke begge.

Træk punktet \(x\) langs aksen.

```jsxgraph
var board = JXG.JSXGraph.initBoard(BOARDID, {
    boundingbox: [-5, 5, 5, -5],   // [xmin, ymax, xmax, ymin]
    axis: true,
    keepaspectratio: false,
    showNavigation: false
});
```
Vigtigt

Brug altid den bogstavelige streng BOARDID. Udvidelsen erstatter den med et entydigt id. Et fast id ødelægger sider med flere grafer.

Indstillinger skrives som attributter på blokken, f.eks. bredde og højde:

```{.jsxgraph width="600" height="300"}
...
```
// Function graph
board.create('functiongraph', [Math.sin], { strokeColor: '#0d6efd' });

// Draggable point
var p = board.create('point', [2, 1], { name: 'P', size: 4 });

// Glider: point constrained to a line or curve
var g = board.create('glider', [1, 0, board.defaultAxes.x], { name: 'x' });

// Slider
var s = board.create('slider', [[0,-3],[4,-3],[0,1,2*Math.PI]], { name: 'a' });

// Use slider value
board.create('functiongraph', [function(x) { return Math.sin(s.Value()*x); }]);

// Text label
board.create('text', [1, 2, function() { return 'x = ' + g.X().toFixed(2); }]);

// Segment
board.create('segment', [p1, p2], { strokeColor: '#198754', dash: 2 });

Med assessment_id og JXG.QuartoAssessment.register(...) melder en graf sin tilstand til en opgave. Opgaven henter den med response: jsxgraph:<assessment_id> og kontrollerer den med sin egen kontrolkode:

Punkt over linjen
Træk punktet \(P\) ind i området over linjen \(y = x\).

Kildekoden til det:

```{.jsxgraph assessment_id="exp-board"}
var board = JXG.JSXGraph.initBoard(BOARDID, {
    boundingbox: [-5, 5, 5, -5], axis: true, showNavigation: false
});
board.create('line', [[0, 0], [1, 1]], { strokeColor: '#0d6efd', fixed: true });
var point = board.create('point', [2, -1], { name: 'P', size: 5 });

JXG.QuartoAssessment.register({
  board: board,
  response: function () {
    return { point: [point.X(), point.Y()] };
  }
});
```

```{math-exercise}
#| mode: custom
#| response: jsxgraph:exp-board
#| embed-response: true
#| checker: |
#|   def check(response, symbols):
#|       x, y = response["point"]
#|       return {"score": 1 if y > x else 0}

Drag the point $P$ into the region above the line $y = x$.
```

response må returnere alle data, der kan skrives som JSON. embed-response: true flytter grafen ind i opgaveboksen. Til opgaver, hvor de studerende bygger en graf af knuder og kanter, findes den færdige editor JXG.QuartoGraphEditor.

**Installation:** gehört zu CTM Assessment, siehe [Überblick und Installation](exp_extensions.qmd)
**Quelle:** [@jsxgraph], [github.com/jsxgraph/jsxgraph-quarto](https://github.com/jsxgraph/jsxgraph-quarto)

Die Fassung von JSXGraph in CTM Assessment beruht auf der Extension `jsxgraph-quarto` und ergänzt eine **Bewertungsbrücke**: Eine Grafik kann damit die Antwort auf eine `math-exercise`-Aufgabe liefern. Die JSXGraph-Bibliothek wird beim Lesen aus dem Netz geladen, ihre Version legt das Paket fest.

```{.yaml filename="seite.qmd"}
engine: markdown      # nur nötig, wenn die Seite auch math-exercise enthält (Quarto 1.10+)
filters:
  - ctm-assessment
```

::: {.callout-warning}
## JSXGraph nicht noch einmal installieren
JSXGraph kommt mit `ctm-assessment` und liegt in `_extensions/jsxgraph/`. Ein zusätzliches `quarto add jsxgraph/jsxgraph-quarto` landet verschachtelt in `_extensions/jsxgraph/jsxgraph/` und wird ignoriert. Beim Bauen erscheint dazu eine Warnung. Steht ein Einzelfilter wie `jsxgraph` im Kopf, ersetzt ihn `ctm-assessment`: Eine Seite führt entweder `ctm-assessment` auf oder einzelne Komponenten, nicht beides.
:::

::: {.panel-tabset}

## Beispiel

```jsxgraph
var board = JXG.JSXGraph.initBoard(BOARDID, {
    boundingbox: [-7, 1.8, 7, -1.8],
    axis: true,
    showNavigation: false
});
board.create('functiongraph', [Math.sin], {
    strokeColor: '#0d6efd', strokeWidth: 2.5
});
var p = board.create('glider', [1.57, 0, board.defaultAxes.x], {
    name: 'x', size: 5, fillColor: '#E91E63'
});
board.create('point', [
    function() { return p.X(); },
    function() { return Math.sin(p.X()); }
], { name: function() { return 'sin(x) ≈ ' + Math.sin(p.X()).toFixed(3); },
     size: 5, fillColor: '#198754', fixed: true });
```

Zieh den Punkt $x$ auf der Achse.

## Häufige Elemente

```{.javascript}
// Funktionsgraph
board.create('functiongraph', [Math.sin], { strokeColor: '#0d6efd' });

// Verschiebbarer Punkt
var p = board.create('point', [2, 1], { name: 'P', size: 4 });

// Gleiter: Punkt, der an eine Linie oder Kurve gebunden ist
var g = board.create('glider', [1, 0, board.defaultAxes.x], { name: 'x' });

// Schieberegler
var s = board.create('slider', [[0,-3],[4,-3],[0,1,2*Math.PI]], { name: 'a' });

// Wert des Schiebereglers benutzen
board.create('functiongraph', [function(x) { return Math.sin(s.Value()*x); }]);

// Beschriftung
board.create('text', [1, 2, function() { return 'x = ' + g.X().toFixed(2); }]);

// Strecke
board.create('segment', [p1, p2], { strokeColor: '#198754', dash: 2 });
```

## Grafik als Antwort

Mit `assessment_id` und `JXG.QuartoAssessment.register(...)` meldet eine Grafik ihren Zustand an eine Aufgabe. Die Aufgabe holt ihn mit `response: jsxgraph:<assessment_id>` und prüft ihn mit eigenem Prüfcode:

```{.jsxgraph assessment_id="exp-board"}
var board = JXG.JSXGraph.initBoard(BOARDID, {
    boundingbox: [-5, 5, 5, -5], axis: true, showNavigation: false
});
board.create('line', [[0, 0], [1, 1]], { strokeColor: '#0d6efd', fixed: true });
var point = board.create('point', [2, -1], { name: 'P', size: 5 });

JXG.QuartoAssessment.register({
  board: board,
  response: function () {
    return { point: [point.X(), point.Y()] };
  }
});
```

The version of JSXGraph in CTM Assessment is based on the `jsxgraph-quarto` extension and adds an **assessment bridge**: a graph can supply the answer to a `math-exercise` exercise. The JSXGraph library is loaded from the network at read time; the package fixes its version.

```{.yaml filename="page.qmd"}
engine: markdown      # only needed if the page also contains math-exercise (Quarto 1.10+)
filters:
  - ctm-assessment
```

::: {.callout-warning}
## Do not install JSXGraph a second time
JSXGraph comes with `ctm-assessment` and sits in `_extensions/jsxgraph/`. An additional `quarto add jsxgraph/jsxgraph-quarto` ends up nested in `_extensions/jsxgraph/jsxgraph/` and is ignored. The build prints a warning about it. If a single filter such as `jsxgraph` is listed in the header, `ctm-assessment` replaces it: a page lists either `ctm-assessment` or individual components, not both.
:::

::: {.panel-tabset}

## Graph as answer

  board: board,

JSXGraph-versionen i CTM Assessment bygger på udvidelsen `jsxgraph-quarto` og tilføjer en **bedømmelsesbro**: en graf kan levere svaret på en `math-exercise`-opgave. JSXGraph-biblioteket hentes fra nettet, når siden læses, og pakken bestemmer, hvilken version der bruges.

```{.yaml filename="side.qmd"}
engine: markdown      # kun nødvendigt, hvis siden også indeholder math-exercise (Quarto 1.10+)
filters:
  - ctm-assessment
```

::: {.callout-warning}
## Installér ikke JSXGraph en gang til
JSXGraph følger med `ctm-assessment` og ligger i `_extensions/jsxgraph/`. Et ekstra `quarto add jsxgraph/jsxgraph-quarto` havner indlejret i `_extensions/jsxgraph/jsxgraph/` og bliver ignoreret. Bygningen udskriver en advarsel om det. Står et enkeltfilter som `jsxgraph` i sidehovedet, erstatter `ctm-assessment` det: en side angiver enten `ctm-assessment` eller enkelte komponenter, ikke begge.
:::
