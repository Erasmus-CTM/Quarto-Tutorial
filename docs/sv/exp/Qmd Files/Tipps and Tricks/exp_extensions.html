Tillägg

Tillägg lär Quarto sådant som Quarto inte kan på egen hand: frågesporter, Python i webbläsaren, uppgifter med automatisk kontroll. Den här handledningen använder två källor:

  • CTM Assessment: ett paket med allt för interaktiva uppgifter (Python-celler, py-exercise, math-exercise, JSXGraph, AI-feedback). Du installerar det med ett kommando.
  • quizdown: frågesporter. Det läggs till separat.
Vad du behöver Var det står
Frågesporter med enkelval, flerval och ordningsföljd quizdown
Redigerbara Python-celler som körs i webbläsaren Python i webbläsaren
Programmeringsuppgifter med dolda tester py-exercise
Matematiska svar som kontrolleras med SymPy math-exercise
Interaktiva grafer, också som svar på en uppgift JSXGraph
AI-feedback, sparade svar, integritet AI-feedback och sparande

För att prova själv leder sidan Uppgift med automatisk kontroll dig steg för steg genom en egen uppgift.

| Mathematische Antworten, geprüft mit SymPy | [math-exercise](exp_ext_mathexercise.qmd) |
| Interaktive Grafiken, auch als Antwort auf eine Aufgabe | [JSXGraph](exp_ext_jsxgraph.qmd) |

## CTM Assessment installieren

Einmal je Projekt, im Projektordner:

::: {.panel-tabset}
### Windows
```{.bash}
quarto add https://erasmus-ctm.github.io/ctm-assessment/ctm-assessment.zip
```

### macOS / Linux
```{.bash}
quarto add https://erasmus-ctm.github.io/ctm-assessment/ctm-assessment.tar.gz
```
:::

Dann einschalten, für das ganze Projekt oder je Seite:

```{.yaml filename="_quarto.yml oder Kopf der Seite"}
filters:
  - ctm-assessment
```

- `_extensions/` gehört mit ins Git-Repository. Zum Aktualisieren denselben Befehl noch einmal ausführen.
- Alte Einzelinstallationen unter `_extensions/Erasmus-CTM/` löschen, das Paket ersetzt sie.
- Braucht Quarto **1.8.27 oder neuer**. Ab Quarto 1.10 brauchen Seiten mit Aufgaben `engine: markdown` im Kopf, siehe [Python im Browser](exp_ext_python.qmd).

### quizdown

quizdown ist nicht Teil des Pakets und wird getrennt installiert und eingeschaltet:

```{.bash}
quarto add parmsam/quizdown
```

```{.yaml filename="seite.qmd"}
filters:
  - parmsam/quizdown
  - ctm-assessment
```

### Sprache der Oberfläche

Knöpfe und Meldungen der Aufgaben richten sich nach `ctm-assessment: lang:` oder nach Quartos eigenem `lang:`. Ein mehrsprachiges Projekt braucht also keine zusätzliche Einstellung, siehe [Mehrsprachige Projekte](exp_multilanguage.qmd).

```{.yaml filename="_quarto.yml"}
ctm-assessment:
  lang: de
```

| Teil | Sprachen |
|---|---|
| gemeinsame Knöpfe, `math-exercise`, `py-exercise` | Englisch, Deutsch, Norwegisch (Bokmål) |
| Speicher und Einstellungen | zusätzlich Nynorsk |
| KI-Feedback | zusätzlich Spanisch |
| Python-Zellen | Englisch, Deutsch, Bokmål, Schwedisch, Dänisch |

Andere Sprachen zeigen Englisch.

::: {.callout-note}
## STACK-Aufgaben
Das Paket enthält auch STACK-Fragen (`{.stack-question}`). Sie brauchen beim Bauen SymPy 1.13.3 für das Python, das Quarto benutzt. Dieses Tutorial geht darauf nicht weiter ein.
:::

## Häufige Stolperstellen

| Was passiert | Ursache und Abhilfe |
|---|---|
| Der Build bricht bei einer Seite mit Aufgaben mit einem Jupyter-Fehler ab | Quarto 1.10 oder neuer: `engine: markdown` in den Kopf dieser Seite |
| `{python}`-Abbildungen fehlen auf einer Seite mit `engine: markdown` | Die Engine schaltet `{python}` ab. Entweder `engine: markdown` weglassen (Jupyter läuft dann, Python muss installiert sein) oder die Abbildungen als Bilddateien einbinden |
| Auf einem anderen Rechner fehlen die Aufgaben | `_extensions/` wurde nicht mit in Git aufgenommen |
| `quarto add` bricht unter Windows ab | die `.zip`-Adresse benutzen, siehe oben |
| `input()` geht in Moodle nicht | Moodle blockiert Service Worker. Das ist eine Grenze der Plattform, siehe [Python im Browser](exp_ext_python.qmd) |
| Der Build bricht wegen eines Schlüssels ab | In einem CTM-Abschnitt steht `api-key`, `token` oder Ähnliches. Raus damit, siehe [KI-Feedback & Speichern](exp_ext_feedback.qmd) |

## Installing CTM Assessment

Once per project, in the project folder:

::: {.panel-tabset}
### Windows
```{.bash}
quarto add https://erasmus-ctm.github.io/ctm-assessment/ctm-assessment.zip
```

### macOS / Linux
```{.bash}
quarto add https://erasmus-ctm.github.io/ctm-assessment/ctm-assessment.tar.gz
```
:::

Then enable it for the whole project or per page:

```{.yaml filename="_quarto.yml or page header"}
filters:
  - ctm-assessment
```

- `_extensions/` belongs in the Git repository. To update, run the same command again.
- Delete old single installs under `_extensions/Erasmus-CTM/`; the package replaces them.
- Requires Quarto **1.8.27 or newer**. From Quarto 1.10, pages with exercises need `engine: markdown` in their header, see [Python in the browser](exp_ext_python.qmd).

### quizdown

quizdown is not part of the package and is installed and enabled separately:

```{.bash}
quarto add parmsam/quizdown
```

```{.yaml filename="page.qmd"}
filters:
  - parmsam/quizdown
  - ctm-assessment
```

### Interface language

Buttons and messages of the exercises follow `ctm-assessment: lang:` or Quarto's own `lang:`. A multilingual project therefore needs no extra setting, see [Multilanguage Projects](exp_multilanguage.qmd).

```{.yaml filename="_quarto.yml"}
ctm-assessment:
  lang: en
```

| Part | Languages |
|---|---|
| shared buttons, `math-exercise`, `py-exercise` | English, German, Norwegian (Bokmål) |
| storage and settings | also Nynorsk |
| AI feedback | also Spanish |
| Python cells | English, German, Bokmål, Swedish, Danish |

Other languages show English.

::: {.callout-note}
## STACK questions
The package also contains STACK questions (`{.stack-question}`). They need SymPy 1.13.3 for the Python that Quarto uses at build time. This tutorial does not go into them.
:::

## Common pitfalls

| What happens | Cause and fix |
|---|---|
| The build stops with a Jupyter error on a page with exercises | Quarto 1.10 or newer: put `engine: markdown` into the header of that page |
| `{python}` figures are missing on a page with `engine: markdown` | The engine switches `{python}` off. Either leave `engine: markdown` out (Jupyter then runs, and Python has to be installed) or include the figures as image files |
| The exercises are missing on another machine | `_extensions/` was not added to Git |
| `quarto add` stops on Windows | use the `.zip` address, see above |
| `input()` does not work in Moodle | Moodle blocks service workers. That is a limit of the platform, see [Python in the browser](exp_ext_python.qmd) |
| The build stops because of a key | A CTM section contains `api-key`, `token` or the like. Remove it, see [AI feedback & saving](exp_ext_feedback.qmd) |

## Installér CTM Assessment

Én gang pr. projekt, i projektmappen:

::: {.panel-tabset}
### Windows
```{.bash}
quarto add https://erasmus-ctm.github.io/ctm-assessment/ctm-assessment.zip
```

### macOS / Linux
```{.bash}
quarto add https://erasmus-ctm.github.io/ctm-assessment/ctm-assessment.tar.gz
```
:::

Slå den derefter til for hele projektet eller pr. side:

```{.yaml filename="_quarto.yml eller sidens hoved"}
filters:
  - ctm-assessment
```

- `_extensions/` hører med i Git-repositoriet. For at opdatere kører du den samme kommando igen.
- Slet gamle enkeltinstallationer under `_extensions/Erasmus-CTM/`, pakken erstatter dem.
- Kræver Quarto **1.8.27 eller nyere**. Fra Quarto 1.10 skal sider med opgaver have `engine: markdown` i hovedet, se [Python i browseren](exp_ext_python.qmd).

### quizdown

quizdown er ikke en del af pakken og installeres og slås til separat:

```{.bash}
quarto add parmsam/quizdown
```

```{.yaml filename="side.qmd"}
filters:
  - parmsam/quizdown
  - ctm-assessment
```

### Grænsefladens sprog

Knapper og meddelelser i opgaverne følger `ctm-assessment: lang:` eller Quartos eget `lang:`. Et flersproget projekt behøver altså ingen ekstra indstilling, se [Flersprogede projekter](exp_multilanguage.qmd).

```{.yaml filename="_quarto.yml"}
ctm-assessment:
  lang: da
```

| Del | Sprog |
|---|---|
| fælles knapper, `math-exercise`, `py-exercise` | engelsk, tysk, norsk (bokmål) |
| lagring og indstillinger | desuden nynorsk |
| AI-feedback | desuden spansk |
| Python-celler | engelsk, tysk, bokmål, svensk, dansk |

Andre sprog viser engelsk.

## Almindelige faldgruber

| Hvad der sker | Årsag og løsning |
|---|---|
| Bygningen stopper med en Jupyter-fejl på en side med opgaver | Quarto 1.10 eller nyere: skriv `engine: markdown` i hovedet på siden |
| `{python}`-figurer mangler på en side med `engine: markdown` | Motoren slår `{python}` fra. Enten udelader du `engine: markdown` (Jupyter kører så, og Python skal være installeret) eller du indsætter figurerne som billedfiler |
| Opgaverne mangler på en anden computer | `_extensions/` blev ikke taget med i Git |
| `quarto add` stopper i Windows | brug `.zip`-adressen, se ovenfor |
| `input()` virker ikke i Moodle | Moodle blokerer service workers. Det er en begrænsning i platformen, se [Python i browseren](exp_ext_python.qmd) |
| Bygningen stopper på grund af en nøgle | En CTM-sektion indeholder `api-key`, `token` eller lignende. Fjern den, se [AI-feedback og lagring](exp_ext_feedback.qmd) |
