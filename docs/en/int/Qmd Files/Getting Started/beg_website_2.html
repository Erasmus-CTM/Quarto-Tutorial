Create a Website

1 — Open your project folder in VS Code

Create a new empty folder on your computer (e.g. on the Desktop). Name it something short without spaces, like my-website.

In VS Code click File → Open Folder and select your new folder.

WarningVS Code will ask: “Do you trust the authors?”

This dialog appears the first time you open any folder. Click Yes, I trust the authors — otherwise VS Code runs in a restricted mode and some features will not work.

2 — Create a Quarto Website project

① Create a new Quarto project

Go to File → New File…. A small menu appears — select Quarto Project.

Select Website Project and choose your project folder.

② Your project files are ready

Quarto created four files:

  • _quarto.yml — settings: title, navigation, theme
  • index.qmd — your homepage
  • about.qmd — an example second page
  • styles.css — optional custom styling

3 — Preview your website

① Click the Preview button in the top-right corner of the editor

Click the small preview icon in the top-right corner of the coding window. VS Code opens the terminal automatically, renders your site, and shows a live preview in a new panel on the right — no browser needed.

Note🔍 Other ways to preview and render

Render files (create output without previewing)

If you just want to produce the output files without opening any preview, open the Terminal via View → Terminal and run:

Terminal
quarto render

This creates all output files in the _site folder (or docs/ if you configured it that way). Use this when you are ready to publish — see Publish your Website →.

Preview in your browser

You have two options:

  • Open the generated HTML files from the _site folder directly in your browser (double-click them in File Explorer).
  • Or run quarto preview in the Terminal — this starts a local server and opens your site in the browser automatically. The browser updates every time you save a file.
Terminal
quarto preview

Tip✅ Your first Quarto website is running!

Next steps:

  • Edit index.qmd and save — the preview updates immediately
  • Change the title: in _quarto.yml to rename your site
  • Ready to go online? Continue with Publish your Website →

## 1 – Projektordner in VS Code öffnen

Lege auf deinem Rechner einen neuen, leeren Ordner an (zum Beispiel auf dem Desktop). Gib ihm einen kurzen Namen ohne Leerzeichen, etwa `my-website`.

Klicke in VS Code auf **File → Open Folder** und wähle den neuen Ordner aus.

::: {.callout-warning}
## VS Code fragt: „Do you trust the authors?“

![](../../Img Files/Getting Started/trust_file_authors.png)

Dieses Fenster erscheint, wenn du einen Ordner zum ersten Mal öffnest. Klicke auf **Yes, I trust the authors**, sonst läuft VS Code in einem eingeschränkten Modus und manches funktioniert nicht.
:::

---

## 2 – Ein Quarto-Website-Projekt anlegen

**① Neues Quarto-Projekt anlegen**

![](../../Img Files/Getting Started/create_new_file_menu.png)

Gehe auf **File → New File…**. Es erscheint ein kleines Menü, wähle dort **Quarto Project**.

![](../../Img Files/Getting Started/quarto_project_choice.png)

Wähle **Website Project** und dann deinen Projektordner.

---

**② Deine Projektdateien sind da**

![](../../Img Files/Getting Started/website_project_files.png)

Quarto hat vier Dateien angelegt:

- `_quarto.yml`: Einstellungen wie Titel, Navigation und Aussehen
- `index.qmd`: deine Startseite
- `about.qmd`: eine zweite Seite als Beispiel
- `styles.css`: eigenes Aussehen, wenn du möchtest

---

## 3 – Vorschau der Website

**① Auf den Vorschau-Knopf oben rechts im Editor klicken**

![](../../Img Files/Getting Started/Website_preview_button_in_vscode.png)

Klicke auf das kleine Vorschau-Symbol oben rechts im Editorfenster. VS Code öffnet von selbst das Terminal, baut deine Seite und zeigt rechts eine Vorschau, die sich laufend aktualisiert. Einen Browser brauchst du dafür nicht.

---

::: {.callout-note collapse="true"}
## 🔍 Andere Wege zu Vorschau und fertigen Dateien

**Dateien bauen (Ausgabe erzeugen, ohne Vorschau)**

Wenn du nur die fertigen Dateien haben möchtest, öffne das **Terminal** über **View → Terminal** und gib ein:

```{.bash filename="Terminal"}
quarto render
```

Damit entstehen alle Ausgabedateien im Ordner `_site` (oder in `docs/`, wenn du das so eingestellt hast). Das brauchst du, wenn du veröffentlichen willst, siehe [Website veröffentlichen →](beg_website_3.qmd).

---

**Vorschau im Browser**

Du hast zwei Möglichkeiten:

- Öffne die erzeugten HTML-Dateien aus dem Ordner `_site` direkt im Browser (Doppelklick im Datei-Explorer).
- Oder gib im Terminal `quarto preview` ein. Das startet einen lokalen Server und öffnet deine Seite im Browser. Bei jedem Speichern aktualisiert sie sich.

```{.bash filename="Terminal"}
quarto preview
```

![](../../Img Files/Getting Started/website_with_terminal_quartopreview.png)
:::


---

::: {.callout-tip}
## ✅ Deine erste Quarto-Website läuft!

**Wie es weitergeht:**

- Ändere `index.qmd` und speichere, die Vorschau zeigt es sofort
- Ändere `title:` in `_quarto.yml`, um deine Seite umzubenennen
- Bereit für das Internet? Weiter mit [Website veröffentlichen →](beg_website_3.qmd)
:::

## 🔍 Andre måder at forhåndsvise og rendere på

```{.bash filename="Terminal"}
quarto preview
```

## 1 – Öppna projektmappen i VS Code

Klicka i VS Code på **File → Open Folder** och välj den nya mappen.

::: {.callout-warning}
## VS Code frågar: "Do you trust the authors?"

![](../../Img Files/Getting Started/trust_file_authors.png)

Den här dialogrutan visas första gången du öppnar en mapp. Klicka på **Yes, I trust the authors**, annars körs VS Code i ett begränsat läge där vissa funktioner inte fungerar.
:::

## 2 – Skapa ett Quarto-webbplatsprojekt

**① Skapa ett nytt Quarto-projekt**

![](../../Img Files/Getting Started/create_new_file_menu.png)

Gå till **File → New File…**. En liten meny visas, välj **Quarto Project**.

![](../../Img Files/Getting Started/quarto_project_choice.png)

Välj **Website Project** och sedan din projektmapp.

---

**② Dina projektfiler är klara**

![](../../Img Files/Getting Started/website_project_files.png)

Quarto har skapat fyra filer:

- `_quarto.yml`: inställningar som titel, navigering och tema
- `index.qmd`: din startsida
- `about.qmd`: en andra sida som exempel
- `styles.css`: egen formgivning, om du vill

---

## 3 – Förhandsgranska webbplatsen

**① Klicka på knappen Preview uppe till höger i redigeraren**

![](../../Img Files/Getting Started/Website_preview_button_in_vscode.png)

Klicka på den lilla förhandsgranskningssymbolen uppe till höger i kodfönstret. VS Code öppnar terminalen automatiskt, renderar webbplatsen och visar en förhandsgranskning i en ny panel till höger. Du behöver ingen webbläsare.

---

::: {.callout-note collapse="true"}
## 🔍 Andra sätt att förhandsgranska och rendera

**Rendera filer (skapa utdata utan förhandsgranskning)**

Om du bara vill skapa utdatafilerna utan att öppna någon förhandsgranskning, öppna **terminalen** via **View → Terminal** och kör:

```{.bash filename="Terminal"}
quarto render
```

Då skapas alla utdatafiler i mappen `_site` (eller `docs/` om du har ställt in det). Använd det här när du är redo att publicera, se [Publicera webbplatsen →](beg_website_3.qmd).

---

**Förhandsgranska i webbläsaren**

Du har två möjligheter:

- Öppna de skapade HTML-filerna i mappen `_site` direkt i webbläsaren (dubbelklicka på dem i Utforskaren).
- Eller kör `quarto preview` i terminalen. Då startas en lokal server och webbplatsen öppnas automatiskt i webbläsaren. Webbläsaren uppdateras varje gång du sparar en fil.

```{.bash filename="Terminal"}
quarto preview
```

![](../../Img Files/Getting Started/website_with_terminal_quartopreview.png)
:::
