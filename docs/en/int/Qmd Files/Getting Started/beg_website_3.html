Publish your Website

NoteOfficial Documentation

Quarto supports several publishing options. See all of them at quarto.org/docs/publishing.

This guide uses GitHub Pages — a free hosting service that makes your website publicly available at a github.io address.

You will need a free account at github.com. Create one if you don’t have one yet.

1 — Tell Quarto to output into a docs folder

① Open _quarto.yml and add the output folder

Open your _quarto.yml file and add output-dir: docs to the project: section, exactly as shown above. GitHub Pages expects your website files to live in a folder named docs.

② Render your website

Open the Terminal via View → Terminal and run:

Terminal
quarto render

Quarto builds your entire website into the docs/ folder. You will see it appear in the file explorer on the left.

2 — Create a repository on GitHub

① Go to GitHub and create a new repository

Log in at github.com, click the + icon in the top right and select New repository. Give it a name — this will become part of your website’s address.

② Set it to Public and create

Make sure Public is selected. Leave all other options at their defaults and click Create repository.

3 — Upload your files

① Find the upload link

Your new empty repository opens. Click uploading an existing file in the middle of the page.

② Drag your project files onto the page

Drag all files and folders from your project folder directly onto the GitHub upload page. Include everything: docs/, _quarto.yml, index.qmd, styles.css, and any other files.

Warning

Do not upload just the docs/ folder contents — upload the entire project folder’s contents so GitHub has everything it needs.

GitHub will show a “Processing your files…” spinner while uploading.

③ Commit the files

After uploading, scroll down. You will see a “Commit changes” dialog. You can leave the message as “Initial Push” or write your own. Click Commit changes.

4 — Enable GitHub Pages

① Open the repository Settings

Click the Settings tab at the top of your repository page.

② Find “Pages” in the left sidebar

Scroll down the left sidebar and click Pages.

③ Select branch main and folder /docs

Under Branch, click the dropdown that says None and select main.

A second dropdown appears for the folder. Click it and select /docs.

④ Save

Click Save. GitHub will now start building and deploying your site.

5 — Your site is live

① Wait for deployment

Go back to the main page of your repository. On the right side you will see a Deployments section. Wait until it shows a green checkmark — this usually takes 1–2 minutes.

Click on the deployment to find your public website address — it looks like https://yourusername.github.io/your-repo-name/.

TipUpdating your site later

Whenever you make changes:

  1. Run quarto render in VS Code’s Terminal (or click the Preview button and close it) to rebuild the docs/ folder
  2. Go to your GitHub repository → drag the updated docs/ folder onto the file list → Commit

GitHub Pages will redeploy automatically within a minute or two.

Diese Anleitung nutzt **GitHub Pages**, einen kostenlosen Dienst, der deine Website unter einer `github.io`-Adresse öffentlich erreichbar macht.

Du brauchst ein kostenloses Konto bei [github.com](https://github.com). Lege eins an, falls du noch keins hast.

## 1 – Quarto in einen Ordner `docs` schreiben lassen

**① `_quarto.yml` öffnen und den Ausgabeordner eintragen**

![](../../Img Files/Getting Started/github_pages_Change_Output_dir_in_yml.png)

Öffne deine `_quarto.yml` und ergänze im Abschnitt `project:` die Zeile `output-dir: docs`, genau wie im Bild. GitHub Pages erwartet die Dateien der Website in einem Ordner namens `docs`.

---

**② Website bauen**

Öffne das **Terminal** über **View → Terminal** und gib ein:

```{.bash filename="Terminal"}
quarto render
```

Quarto baut die ganze Website in den Ordner `docs/`. Er erscheint links in der Dateiübersicht.

---

## 2 – Ein Repository auf GitHub anlegen

**① Auf GitHub ein neues Repository anlegen**

![](../../Img Files/Getting Started/github_pages_create_new_repo_1.png)

Melde dich bei [github.com](https://github.com) an, klicke oben rechts auf das **+** und wähle **New repository**. Gib ihm einen Namen, er wird Teil der Adresse deiner Website.

---

**② Auf Public stellen und anlegen**

![](../../Img Files/Getting Started/github_pages_create_new_repo_2.png)

Achte darauf, dass **Public** ausgewählt ist. Alles andere bleibt, wie es ist. Klicke auf **Create repository**.

---

## 3 – Dateien hochladen

**① Den Link zum Hochladen finden**

![](../../Img Files/Getting Started/github_pages_upload_existing_files.png)

Dein neues, leeres Repository öffnet sich. Klicke in der Mitte der Seite auf **uploading an existing file**.

---

**② Projektdateien auf die Seite ziehen**

Ziehe alle Dateien und Ordner aus deinem Projektordner direkt auf die Upload-Seite von GitHub. Nimm alles mit: `docs/`, `_quarto.yml`, `index.qmd`, `styles.css` und alle weiteren Dateien.

::: {.callout-warning}
Lade **nicht** nur den Inhalt von `docs/` hoch, sondern den Inhalt des ganzen Projektordners, damit GitHub alles hat, was es braucht.
:::

Während des Hochladens zeigt GitHub **„Processing your files...“** an.

![](../../Img Files/Getting Started/github_pages_commiting_github.png)

---

**③ Dateien committen**

![](../../Img Files/Getting Started/github_pages_dont_forget_to_press_commit.png)

Scrolle nach dem Hochladen nach unten. Dort steht das Feld **„Commit changes“**. Du kannst die Nachricht „Initial Push“ lassen oder eine eigene schreiben. Klicke auf **Commit changes**.

---

## 4 – GitHub Pages einschalten

**① Die Einstellungen des Repositorys öffnen**

![](../../Img Files/Getting Started/github_pages_find_settings_top_right.png)

Klicke oben auf der Seite deines Repositorys auf den Reiter **Settings**.

---

**② In der linken Leiste „Pages“ suchen**

![](../../Img Files/Getting Started/github_pages_sidebar_look_for_pages.png)

Scrolle in der linken Leiste nach unten und klicke auf **Pages**.

---

**③ Branch `main` und Ordner `/docs` auswählen**

![](../../Img Files/Getting Started/github_pages_select_branch_main.png)

Klicke unter **Branch** auf das Auswahlfeld, in dem **None** steht, und wähle **main**.

---

![](../../Img Files/Getting Started/github_pages_select_folder_docs.png)

Daneben erscheint ein zweites Auswahlfeld für den Ordner. Klicke darauf und wähle **/docs**.

---

**④ Speichern**

![](../../Img Files/Getting Started/github_pages_should_look_like.png)

Klicke auf **Save**. GitHub beginnt jetzt, deine Seite zu bauen und bereitzustellen.

---

## 5 – Deine Seite ist online

**① Auf die Bereitstellung warten**

![](../../Img Files/Getting Started/github_pages_the_hosted_website_refreshes_auto_deployment_right_side.png)

Geh zurück auf die Hauptseite deines Repositorys. Rechts steht der Abschnitt **Deployments**. Warte, bis dort ein grüner Haken erscheint, das dauert meist 1–2 Minuten.

Klicke auf die Bereitstellung, dort steht die öffentliche Adresse deiner Website. Sie sieht aus wie `https://deinname.github.io/dein-repo-name/`.

---

::: {.callout-tip}
## Die Seite später aktualisieren

Immer wenn du etwas geändert hast:

1. Gib im Terminal von VS Code `quarto render` ein (oder klicke auf den Vorschau-Knopf und schließe die Vorschau wieder), damit der Ordner `docs/` neu gebaut wird
2. Öffne dein Repository auf GitHub → ziehe den aktualisierten Ordner `docs/` auf die Dateiliste → Commit

GitHub Pages stellt die Seite innerhalb von ein bis zwei Minuten von selbst neu bereit.
:::

**③ Gör en commit av filerna**

![](../../Img Files/Getting Started/github_pages_dont_forget_to_press_commit.png)

Rulla nedåt efter uppladdningen. Där finns dialogen **"Commit changes"**. Du kan låta meddelandet vara "Initial Push" eller skriva ett eget. Klicka på **Commit changes**.

---

## 4 – Aktivera GitHub Pages

**① Öppna repositoryts Settings**

![](../../Img Files/Getting Started/github_pages_find_settings_top_right.png)

Klicka på fliken **Settings** högst upp på repositoryts sida.

---

**② Hitta "Pages" i sidofältet till vänster**

![](../../Img Files/Getting Started/github_pages_sidebar_look_for_pages.png)

Rulla nedåt i sidofältet till vänster och klicka på **Pages**.

---

**③ Välj branchen `main` och mappen `/docs`**

![](../../Img Files/Getting Started/github_pages_select_branch_main.png)

Klicka under **Branch** på listan där det står **None** och välj **main**.

---

![](../../Img Files/Getting Started/github_pages_select_folder_docs.png)

En andra lista för mappen visas. Klicka på den och välj **/docs**.

---

**④ Spara**

![](../../Img Files/Getting Started/github_pages_should_look_like.png)

Klicka på **Save**. GitHub börjar nu bygga och publicera webbplatsen.

---

## 5 – Webbplatsen är publicerad

**① Vänta på publiceringen**

![](../../Img Files/Getting Started/github_pages_the_hosted_website_refreshes_auto_deployment_right_side.png)

Gå tillbaka till repositoryts startsida. Till höger finns avsnittet **Deployments**. Vänta tills det visar en grön bock, det tar oftast 1–2 minuter.

Klicka på publiceringen för att hitta webbplatsens offentliga adress. Den ser ut som `https://dittanvändarnamn.github.io/ditt-repo-namn/`.

---

::: {.callout-tip}
## Uppdatera webbplatsen senare

Varje gång du har ändrat något:

1. Kör `quarto render` i terminalen i VS Code (eller klicka på knappen Preview och stäng den) för att bygga om mappen `docs/`
2. Gå till ditt repository på GitHub → dra den uppdaterade mappen `docs/` till fillistan → Commit

GitHub Pages publicerar om automatiskt inom en eller två minuter.
