Quarto Tips & Tricks

Going further with Quarto

This section is for people who already know how to build Quarto documents and want to go further. All three levels of this tutorial are built with the techniques described here.

NoteOfficial Documentation

The complete Quarto reference is at quarto.org/docs/reference. This section is a curated guide to the parts that are most useful in practice.

What’s covered and where to find it

I want to… Go to
Control output formats, freeze, and profiles The YML File
Configure sidebar sections and collapsing The YML File → Sidebar
Customise the site’s look with themes and CSS The YML File → Styles
Control how code runs (echo, eval, fold, …) The QMD File
Show content only in certain profiles or formats The QMD File → Conditional content
Cross-reference figures, tables, and sections The QMD File → Cross-referencing
Use quizdown, Pyodide, JSXGraph, py-exercise, or math-exercise Extensions
Serve the same project in multiple languages Multilanguage Projects
Look something up quickly Cheatsheet

What you should already know

This section assumes you are comfortable with the following from the other levels:

  • Creating a Quarto website, exercise sheet, or book: Getting Started
  • Running Python in the browser with Pyodide: Interactive Code
  • What interactive Quarto output looks like: Example Page
