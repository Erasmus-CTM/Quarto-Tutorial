Interaktiver Code mit Pyodide

HinweisWas sind Extensions?

Extensions ergänzen Quarto um Funktionen, die nicht eingebaut sind. Du installierst sie einmal je Projektordner. Die vollständige Liste steht unter quarto.org/docs/extensions.

TippLieber eine Kurzfassung?

Dieses Kapitel gibt es als dreiseitiges PDF-Cheatsheet: Installieren und Einschalten, Zellen schreiben und was die Extension mitbringt, knapp gefasst zum Ausdrucken oder Nachschlagen.

Mit Pyodide führen Studierende Python-Code direkt im Browser aus und verändern ihn, ohne Python auf ihrem Rechner zu installieren. Du schreibst den Code einmal, sie klicken auf Code ausführen.

Dieses Tutorial benutzt dafür die Extension pyodide-interaktiv, eine Überarbeitung von coatless-quarto/pyodide. Sie führt Python in einem Web Worker aus, also neben der Seite statt in ihr. Das macht echtes input(), Animationen, einen Knopf „Stopp“ und KI-Feedback möglich, mehr dazu im letzten Abschnitt.

WarnungInteraktiv nur in HTML

Ausführen und Verändern geht nur in der HTML-Ausgabe, also in Websites (format: html) und Büchern. In PDF oder Word erscheint derselbe Code als gewöhnlicher, nicht ausführbarer Code.

1 – Die Extension installieren

① Das Terminal in VS Code öffnen

Öffne das Terminal (die Kommandozeile) über View → Terminal. Unten im Fenster geht ein Bereich auf. Achte darauf, dass der angezeigte Pfad dein Projektordner ist.

② Den Installationsbefehl eingeben

Die Extension liegt unter github.com/Erasmus-CTM/pyodide-interaktiv und wird wie jede andere installiert:

Terminal
quarto add Erasmus-CTM/pyodide-interaktiv

Warte, bis der Befehl fertig ist. Er stellt dabei drei Fragen: ob du der Quelle vertraust, ob du fortfahren willst und ob du die Dokumentation ansehen möchtest. Das ist nur einmal je Projektordner nötig. Danach liegt die Extension im Ordner _extensions/ deines Projekts.

2 – In deiner Datei einschalten

Ergänze im Kopf deiner .qmd-Datei eine Zeile filters::

---
title: "Meine Seite"
format: html
filters:
  - Erasmus-CTM/pyodide-interaktiv
---

3 – Einen interaktiven Codeblock einfügen

Statt eines gewöhnlichen Codeblocks schreibst du {pyodide-python}:

```{pyodide-python}
x = [1, 2, 3, 4, 5]
print(sum(x))
```

4 – Das Ergebnis ansehen

Gib im Terminal quarto preview ein. Im Browser erscheint der Codeblock mit einer Leiste aus Knöpfen. So sieht er aus, du kannst ihn gleich hier ausprobieren:

  • Code ausführen startet den Code (auch mit Shift + Enter). Beim ersten Klick lädt Python, das dauert einige Sekunden.
  • Zurücksetzen stellt deinen ursprünglichen Code wieder her.
  • Feedback holt eine Rückmeldung von einer KI (muss erst eingerichtet werden).
  • Während der Code läuft, erscheint Stopp.

Studierende können den Code ändern und erneut ausführen, ohne etwas zu installieren.

5 – Was die Extension noch kann

  • Zellen teilen sich ihre Variablen. Alle Zellen einer Seite gehören zu einer Python-Sitzung. Eine spätere Zelle kann benutzen, was eine frühere definiert oder importiert hat, aber erst, nachdem die frühere ausgeführt wurde.
  • Echtes input(). Eine Zelle kann anhalten und auf eine Eingabe warten.
  • Animationen. Eine FuncAnimation aus Matplotlib erscheint als Abspieler, mit demselben Code wie auf dem eigenen Rechner.
  • Endlosschleifen sind harmlos. Ein versehentliches while True: blockiert die Seite nicht, Stopp bricht ab.
  • KI-Feedback. Die Hinweise werden mit jedem Klick konkreter.

input() und gemeinsame Variablen kannst du auf der Seite Code der Beispielseite ausprobieren, die Animation auf der Seite Visualisierungen.

TippSollen Studierende Lösungen eintragen?

Die Extension py-exercise bietet Codeblöcke mit versteckten automatischen Tests: Studierende sehen, ob ihre Lösung besteht. Die Extension math-exercise leistet dasselbe für mathematische Antworten, geprüft mit SymPy. Installiert werden beide genauso:

Terminal
quarto add Erasmus-CTM/py-exercise
quarto add Erasmus-CTM/math-exercise

Beispiele zu beiden stehen auf der Beispielseite dieses Tutorials.

**Pyodide** lets students run and edit Python code directly in the browser, with no Python installation on their computer. You write the code once; they click **Run code**.

This tutorial uses the extension **`pyodide-interaktiv`** for that, a rework of `coatless-quarto/pyodide`. It runs Python in a **Web Worker**, that is next to the page rather than inside it. That is what makes real `input()`, animations, a Stop button and AI feedback possible — more on that in the last section.

::: {.callout-warning}
## Interactive in HTML only
Running and editing works only in **HTML output**, that is in websites (`format: html`) and books. In PDF or Word the same code appears as ordinary code that cannot be run.
:::

---

## 1 — Install the extension

**① Open the Terminal in VS Code**

Open the **Terminal** (the command line interface) via **View → Terminal**. A panel opens at the bottom of the screen. Make sure the path shown matches your project folder.

---

**② Run the install command**

The extension is published at **[github.com/Erasmus-CTM/pyodide-interaktiv](https://github.com/Erasmus-CTM/pyodide-interaktiv)** and installs like any other:

```{.bash filename="Terminal"}
quarto add Erasmus-CTM/pyodide-interaktiv
```

Wait until it finishes. It asks three questions: whether you trust the source, whether to continue, and whether you want to view the documentation. This only needs to be done **once per project folder**. Afterwards the extension is in your project's `_extensions/` folder.

---

## 2 — Enable it in your file

Add a `filters:` line to the header block of your `.qmd` file:

```yaml
---
title: "My Page"
format: html
filters:
  - Erasmus-CTM/pyodide-interaktiv
---
```

---

## 3 — Add an interactive code block

Instead of a regular code block, use `{pyodide-python}`:

````markdown
```{pyodide-python}
x = [1, 2, 3, 4, 5]
print(sum(x))
```
````

---

## 4 — See the result

Run `quarto preview` in the Terminal. The code block appears in the browser with a row of buttons. This is what it looks like, and you can try it right here:

```{pyodide-python}
x = [1, 2, 3, 4, 5]
print(sum(x))
```

- **Run code** starts the code (also with `Shift + Enter`). On the first click Python loads, which takes a few seconds.
- **Reset** restores your original code.
- **Feedback** asks an AI for feedback (needs to be set up first).
- While the code is running, **Stop** appears.

Students can edit the code and run it again without installing anything.

---

## 5 — What else the extension can do

- **Cells share their variables.** All cells on a page belong to one Python session. A later cell can use what an earlier one defined or imported, but only after the earlier one has been run.
- **Real `input()`.** A cell can pause and wait for typed input.
- **Animations.** A Matplotlib `FuncAnimation` appears as a player, from the same code you would write on your own computer.
- **Infinite loops are harmless.** An accidental `while True:` does not lock up the page; **Stop** cancels it.
- **AI feedback.** The hints get more concrete with each click.

You can try `input()` and shared variables on the [Code page](../../../beg/Qmd Files/Example Page/ep_code.html) of the Example Page, and the animation on the [Visualizations page](../../../beg/Qmd Files/Example Page/ep_visuals.html).

```{.bash filename="Terminal"}

quarto add Erasmus-CTM/math-exercise
```

Both have examples on the **Example Page** of this tutorial.

Med **Pyodide** kan de studerende køre og ændre Python-kode direkte i browseren uden at installere Python på deres computer. Du skriver koden én gang, de klikker på **Kør koden**.

Denne vejledning bruger udvidelsen **`pyodide-interaktiv`** til det, en omarbejdning af `coatless-quarto/pyodide`. Den kører Python i en **Web Worker**, altså ved siden af siden i stedet for i den. Det er det, der gør rigtig `input()`, animationer, en stopknap og AI-feedback muligt. Mere om det i sidste afsnit.

::: {.callout-warning}
## Interaktivt kun i HTML

## 1 – Installer udvidelsen

**① Åbn terminalen i VS Code**

Åbn **terminalen** (kommandolinjen) via **View → Terminal**. Der åbnes et panel nederst i vinduet. Kontrollér, at den viste sti er din projektmappe.

---

**② Kør installationskommandoen**

Udvidelsen ligger på **[github.com/Erasmus-CTM/pyodide-interaktiv](https://github.com/Erasmus-CTM/pyodide-interaktiv)** og installeres som enhver anden udvidelse:

```{.bash filename="Terminal"}
quarto add Erasmus-CTM/pyodide-interaktiv
```

Vent, til kommandoen er færdig. Den stiller tre spørgsmål: om du stoler på kilden, om du vil fortsætte, og om du vil se dokumentationen. Det er kun nødvendigt **én gang pr. projektmappe**. Bagefter ligger udvidelsen i projektets mappe `_extensions/`.

---

## 2 – Slå den til i din fil

Tilføj en linje `filters:` i hovedet på din `.qmd`-fil:

```yaml
---
title: "My Page"

  - Erasmus-CTM/pyodide-interaktiv
---
```

## 3 – Tilføj en interaktiv kodeblok

I stedet for en almindelig kodeblok skriver du `{pyodide-python}`:

````markdown
```{pyodide-python}
x = [1, 2, 3, 4, 5]
print(sum(x))
```
````

---

## 4 – Se resultatet

Kør `quarto preview` i terminalen. Kodeblokken vises i browseren med en række knapper. Sådan ser den ud, og du kan prøve den med det samme her:

```{pyodide-python}
x = [1, 2, 3, 4, 5]
print(sum(x))
```

- **Kør koden** starter koden (også med `Shift + Enter`). Ved første klik indlæses Python, det tager nogle sekunder.
- **Nulstil** gendanner din oprindelige kode.
- **Feedback** beder en AI om feedback (skal sættes op først).
- Mens koden kører, vises **Stop**.

De studerende kan ændre koden og køre den igen uden at installere noget.

---

## 5 – Hvad udvidelsen ellers kan

- **Celler deler variabler.** Alle celler på en side hører til én og samme Python-session. En senere celle kan bruge det, en tidligere har defineret eller importeret, men først når den tidligere er kørt.
- **Rigtig `input()`.** En celle kan stoppe og vente på input.
- **Animationer.** En `FuncAnimation` fra Matplotlib vises som en afspiller, med den samme kode, som du ville skrive på din egen computer.
- **Uendelige løkker er ufarlige.** En `while True:` ved en fejl låser ikke siden, **Stop** afbryder.
- **AI-feedback.** Hintene bliver mere konkrete for hvert klik.

`input()` og delte variabler kan du prøve på siden [Kode](../../../beg/Qmd Files/Example Page/ep_code.html) i eksempelsiden og animationen på siden [Visualiseringer](../../../beg/Qmd Files/Example Page/ep_visuals.html).

## Vad är tillägg?
Tillägg (extensions) ger Quarto funktioner som inte är inbyggda. Du installerar dem en gång per projektmapp.
Hela listan finns på **[quarto.org/docs/extensions](https://quarto.org/docs/extensions/)**.
:::

::: {.callout-tip}
## Vill du hellre ha en kortversion?
Det här kapitlet finns som en [PDF-lathund](beg_extensions_cheatsheet.qmd) på tre sidor: installera och aktivera, skriva celler och vad tillägget ger dig, kortfattat för utskrift eller snabb uppslagning.
:::

Med **Pyodide** kan studenterna köra och ändra Python-kod direkt i webbläsaren, utan att installera Python på sin dator. Du skriver koden en gång, de klickar på **Kör koden**.

Den här handledningen använder tillägget **`pyodide-interaktiv`** till det, en omarbetning av `coatless-quarto/pyodide`. Det kör Python i en **Web Worker**, alltså bredvid sidan i stället för i den. Det är det som gör riktigt `input()`, animationer, en stoppknapp och AI-feedback möjligt. Mer om det i sista avsnittet.

::: {.callout-warning}
## Interaktivt bara i HTML
Att köra och ändra kod fungerar bara i **HTML**, alltså i webbplatser (`format: html`) och böcker. I PDF eller Word visas samma kod som vanlig kod som inte går att köra.
:::

---

## 1 – Installera tillägget

**① Öppna terminalen i VS Code**

Öppna **terminalen** (kommandoraden) via **View → Terminal**. En panel öppnas längst ner i fönstret. Kontrollera att sökvägen som visas är din projektmapp.

---

**② Kör installationskommandot**

Tillägget finns på **[github.com/Erasmus-CTM/pyodide-interaktiv](https://github.com/Erasmus-CTM/pyodide-interaktiv)** och installeras som vilket annat tillägg som helst:

```{.bash filename="Terminal"}
quarto add Erasmus-CTM/pyodide-interaktiv
```

Vänta tills kommandot är klart. Det ställer tre frågor: om du litar på källan, om du vill fortsätta och om du vill se dokumentationen. Det här behövs bara **en gång per projektmapp**. Efteråt ligger tillägget i projektets mapp `_extensions/`.

---

## 2 – Aktivera det i din fil

Lägg till en rad `filters:` i huvudet på din `.qmd`-fil:

```yaml
---
title: "My Page"
format: html
filters:
  - Erasmus-CTM/pyodide-interaktiv
---
```

---

## 3 – Lägg till ett interaktivt kodblock

I stället för ett vanligt kodblock skriver du `{pyodide-python}`:

````markdown
```{pyodide-python}
x = [1, 2, 3, 4, 5]
print(sum(x))
```
````

---

## 4 – Se resultatet

Kör `quarto preview` i terminalen. Kodblocket visas i webbläsaren med en rad knappar. Så här ser det ut, och du kan prova det direkt här:

```{pyodide-python}
x = [1, 2, 3, 4, 5]
print(sum(x))
```

- **Kör koden** startar koden (också med `Shift + Enter`). Vid första klicket laddas Python, det tar några sekunder.
- **Återställ** återställer din ursprungliga kod.
- **Feedback** ber en AI om återkoppling (måste ställas in först).
- Medan koden körs visas **Stoppa**.

Studenterna kan ändra koden och köra den igen utan att installera något.

---

## 5 – Vad tillägget mer kan

- **Celler delar variabler.** Alla celler på en sida hör till en och samma Python-session. En senare cell kan använda det som en tidigare har definierat eller importerat, men först när den tidigare har körts.
- **Riktigt `input()`.** En cell kan stanna och vänta på inmatning.
- **Animationer.** En `FuncAnimation` från Matplotlib visas som en spelare, med samma kod som du skulle skriva på din egen dator.
- **Oändliga loopar är ofarliga.** Ett `while True:` av misstag låser inte sidan, **Stoppa** avbryter.
- **AI-feedback.** Ledtrådarna blir mer konkreta för varje klick.

`input()` och delade variabler kan du prova på sidan [Kod](../../../beg/Qmd Files/Example Page/ep_code.html) i exempelsidan, och animationen på sidan [Visualiseringar](../../../beg/Qmd Files/Example Page/ep_visuals.html).

## Ska studenterna fylla i lösningar?
Tillägget `py-exercise` ger kodblock med dolda automatiska tester: studenterna ser om deras lösning klarar testerna. Tillägget `math-exercise` gör samma sak för matematiska svar, kontrollerade med SymPy. Båda installeras på samma sätt:

```{.bash filename="Terminal"}
quarto add Erasmus-CTM/py-exercise
quarto add Erasmus-CTM/math-exercise
```

Exempel på båda finns på **exempelsidan** i den här handledningen.
