Aufgabe mit automatischer Prüfung

Ihre Antworten werden nur in diesem Browser gespeichert.

TippLieber eine Kurzfassung?

Dieses Kapitel gibt es als PDF-Cheatsheet: die Schritte und die Schreibweise der beiden Aufgabentypen, knapp gefasst zum Ausdrucken oder Nachschlagen.

Eine Aufgabe mit automatischer Prüfung sagt Studierenden sofort, ob ihre Lösung stimmt. Du schreibst die Aufgabe und die richtige Antwort einmal, die Prüfung läuft im Browser. Es gibt zwei Arten:

Aufgabe Studierende Geprüft wird
py-exercise ergänzen eine Python-Funktion mit versteckten Tests (assert)
math-exercise tippen eine mathematische Antwort mit SymPy, gleichwertige Schreibweisen zählen
WarnungInteraktiv nur in HTML

Prüfen geht nur in der HTML-Ausgabe, also in Websites (format: html) und Büchern. In PDF oder Word erscheint nur der Text der Aufgabe.

1 – Das Paket installieren

Beide Aufgabentypen stecken im Paket CTM Assessment. Falls du es noch nicht installiert hast, öffne das Terminal in VS Code (View → Terminal) und gib im Projektordner ein:

  • Windows
  • macOS / Linux
Terminal
quarto add https://erasmus-ctm.github.io/ctm-assessment/ctm-assessment.zip
Terminal
quarto add https://erasmus-ctm.github.io/ctm-assessment/ctm-assessment.tar.gz

Das ist nur einmal je Projektordner nötig. Dieselben Schritte stehen ausführlicher auf der Seite Interaktiver Code mit Pyodide.

2 – Die Seite vorbereiten

Ergänze im Kopf deiner .qmd-Datei zwei Dinge:

---
title: "Meine Aufgaben"
format: html
engine: markdown
filters:
  - ctm-assessment
---

filters: schaltet das Paket ein. engine: markdown brauchst du ab Quarto 1.10 auf Seiten mit Aufgaben, sonst bricht der Build bei Jupyter ab.

3 – Eine Python-Aufgabe schreiben

Ein py-exercise-Block hat zwei Teile, getrennt durch die Zeile ## TESTS ##. Oben steht, was die Studierenden sehen, darunter die versteckten Tests:

```{py-exercise}
def quadrat(x):
    """Gib das Quadrat von x zurück."""
    # Deine Lösung
    pass

## TESTS ##
assert quadrat(3) == 9,  "quadrat(3) sollte 9 sein"
assert quadrat(-2) == 4, "quadrat(-2) sollte 4 sein"
```

Der Text hinter dem Komma eines assert ist die Rückmeldung, wenn der Test scheitert. Schreib ihn so, als würdest du mit den Studierenden sprechen.

4 – Eine Mathe-Aufgabe schreiben

Bei math-exercise steht die richtige Antwort im Aufgabentext, in eckigen Klammern hinter einem Unterstrich:

```{math-exercise}
#| label: kreisflaeche
#| vars: r
Ein Kreis hat den Radius $r = 3$. Gib seinen Flächeninhalt exakt an (schreibe pi für π):

$A =$ _[pi*9]
```

#| vars: nennt die Symbole, die in der Antwort vorkommen dürfen. Die Antwort in [...] ist ein SymPy-Ausdruck. Probier es aus: pi*9, 9*pi und 3**2*pi gelten alle als richtig.

5 – Das Ergebnis ansehen

Gib im Terminal quarto preview ein. Beim ersten Klick auf Code ausführen oder Überprüfen lädt Python, das dauert einige Sekunden. Dann zeigen die Aufgaben:

  • bei py-exercise einen Editor mit den Knöpfen zum Ausführen und Zurücksetzen. Nach dem Ausführen steht dort, welche Tests bestehen und welche Meldung bei einem Fehler erscheint.
  • bei math-exercise ein Eingabefeld und einen Knopf Überprüfen, der das Ergebnis neben das Feld schreibt.

Mach mit Absicht einen Fehler und schau, ob die Rückmeldung den Studierenden weiterhilft. Probier auch die richtige Lösung aus.

6 – Hilfe von einer KI (freiwillig)

Jede Aufgabe kann einen Knopf Feedback bekommen. Er erzeugt aus der Aufgabe und der aktuellen Antwort einen fertigen Text, den Studierende in eine KI ihrer Wahl einfügen. Für py-exercise schaltest du das ein und nennst in jeder Aufgabe den Auftrag:

---
py-exercise:
  feedback: true
---

```{py-exercise}
#| task: Ergänze quadrat so, dass es das Quadrat von x zurückgibt.
def quadrat(x):
    pass

## TESTS ##
assert quadrat(3) == 9
```

Die Tests und die erwartete Lösung werden nie mitgeschickt. Wie du Hinweisstufen festlegst und eine Seite ganz ohne KI baust, steht auf der Seite KI-Feedback & Speichern.

7 – Antworten bleiben erhalten

Was Studierende eintragen, bleibt im Browser ihres Geräts. Beim nächsten Besuch ist es wieder da. Auf einen Server geht dabei nichts. Studierende können das im Einstellungsdialog ausschalten, ihre Antworten exportieren oder löschen.

An exercise with automatic checking tells students at once whether their solution is right. You write the exercise and the correct answer once, and the check runs in the browser. There are two kinds:

| Exercise | Students | Checked |
|---|---|---|
| `py-exercise` | complete a Python function | with hidden tests (`assert`) |
| `math-exercise` | type a mathematical answer | with SymPy, equivalent forms count |

::: {.callout-warning}
## Interactive in HTML only
Checking works only in **HTML output**, that is in websites (`format: html`) and books. In PDF or Word only the text of the exercise appears.
:::

## 2 — Prepare the page

Add two things to the header of your `.qmd` file:

```yaml
---
title: "My exercises"
format: html
engine: markdown
filters:
  - ctm-assessment
---
```

`filters:` switches the package on. From Quarto 1.10 on you need `engine: markdown` on pages with exercises, otherwise the build stops at Jupyter.

---

## 3 — Write a Python exercise

A `py-exercise` block has two parts, separated by the line `## TESTS ##`. Above it is what students see, below it the hidden tests:

````markdown
```{py-exercise}
def square(x):
    """Return x squared."""
    # Your solution here
    pass

## TESTS ##
assert square(3) == 9,  "square(3) should be 9"
assert square(-2) == 4, "square(-2) should be 4"
```
````

The text after the comma of an `assert` is the message when the test fails. Write it as if you were talking to the students.

This is what the exercise looks like; try it right here:

```{py-exercise}
#| label: check-square
def square(x):
    """Return x squared."""
    # Your solution here
    pass

## TESTS ##
assert square(3) == 9,  "square(3) should be 9"
assert square(-2) == 4, "square(-2) should be 4"
```

---

## 4 — Write a maths exercise

In `math-exercise` the correct answer is in the question text, in square brackets after an underscore:

````markdown
```{math-exercise}
#| label: circle-area
#| vars: r
A circle has radius $r = 3$. Give its area exactly (write pi for π):

$A =$ _[pi*9]
```
````

`#| vars:` names the symbols that may appear in the answer. The answer in `[...]` is a SymPy expression. Try it: `pi*9`, `9*pi` and `3**2*pi` all count as correct.

```{math-exercise}
#| label: check-circle-area
#| vars: r
A circle has radius $r = 3$. Give its area exactly (write pi for π):

$A =$ _[pi*9]
```

---

## 5 — See the result

Run `quarto preview` in the Terminal. On the first click on **Run code** or **Check**, Python loads, which takes a few seconds. Then the exercises show:

- for `py-exercise`, an editor with buttons to run and reset. After running, it shows which tests pass and which message appears for a failure.
- for `math-exercise`, an input field and a **Check** button that writes the result next to the field.

Make a mistake on purpose and see whether the message helps students to move on. Try the correct solution too.

---

## 6 — Help from an AI (optional)

Every exercise can get a **Feedback** button. It turns the exercise and the current answer into a ready-made text that students paste into an AI of their choice. For `py-exercise` you switch it on and state the assignment in every exercise:

````markdown
---
py-exercise:
  feedback: true
---

```{py-exercise}
#| task: Complete square so that it returns the square of x.
def square(x):
    pass

## TESTS ##
assert square(3) == 9
```
````

The tests and the expected solution are never sent. How to set hint levels and how to build a page without any AI is described on the page [AI feedback & saving](../../../exp/Qmd Files/Tipps and Tricks/exp_ext_feedback.html).

---

## 7 — Answers are kept

What students enter stays in the browser of their device. On the next visit it is back. Nothing goes to a server. Students can switch that off in the settings dialog, export their answers or delete them.

## 3 – Skriva en Python-uppgift

Ett `py-exercise`-block har två delar, åtskilda av raden `## TESTS ##`. Ovanför står det studenterna ser, under står de dolda testerna:

````markdown
```{py-exercise}
def kvadrat(x):

    # Din lösning här
    pass

## TESTS ##
assert kvadrat(3) == 9,  "kvadrat(3) ska vara 9"
assert kvadrat(-2) == 4, "kvadrat(-2) ska vara 4"
```
````

Texten efter kommatecknet i en `assert` är meddelandet när testet misslyckas. Skriv det som om du pratade med studenterna.

Så här ser uppgiften ut, prova den direkt:

```{py-exercise}
#| label: check-kvadrat
def kvadrat(x):
```

## 5 – Se resultatet

## 6 – Hjälp av en AI (frivilligt)

Varje uppgift kan få en knapp **Feedback**. Den gör uppgiften och det aktuella svaret till en färdig text som studenterna klistrar in i en AI efter eget val. För `py-exercise` slår du på det och anger uppdraget i varje uppgift:

````markdown
---
py-exercise:
  feedback: true
---

```{py-exercise}
#| task: Komplettera kvadrat så att den returnerar kvadraten av x.
def kvadrat(x):
    pass

## TESTS ##
assert kvadrat(3) == 9
```
````

Testerna och den förväntade lösningen skickas aldrig. Hur du ställer in ledtrådsnivåer och bygger en sida helt utan AI beskrivs på sidan [AI-feedback och sparande](../../../exp/Qmd Files/Tipps and Tricks/exp_ext_feedback.html).

## 1 – Installere pakken

Begge oppgavetypene ligger i pakken **CTM Assessment**. Hvis du ikke har installert den ennå, åpner du **terminalen** i VS Code (**View → Terminal**) og skriver i prosjektmappen:

::: {.panel-tabset}
### Windows
```{.bash filename="Terminal"}
quarto add https://erasmus-ctm.github.io/ctm-assessment/ctm-assessment.zip
```

### macOS / Linux
```{.bash filename="Terminal"}
quarto add https://erasmus-ctm.github.io/ctm-assessment/ctm-assessment.tar.gz
```
:::

Det trengs bare **én gang per prosjektmappe**. De samme trinnene er beskrevet mer utførlig på siden [Interaktiv kode med Pyodide](beg_extensions.qmd).

---

## 2 – Forberede siden

Legg til to ting i hodet på `.qmd`-filen din:

```yaml
---
title: "Oppgavene mine"
format: html
engine: markdown
filters:
  - ctm-assessment
---
```

`filters:` slår på pakken. Fra Quarto 1.10 trenger du `engine: markdown` på sider med oppgaver, ellers stopper byggingen ved Jupyter.

---

## 3 – Skrive en Python-oppgave

En `py-exercise`-blokk har to deler, adskilt av linjen `## TESTS ##`. Over står det studentene ser, under står de skjulte testene:

````markdown
```{py-exercise}
def kvadrat(x):
    """Returner kvadratet av x."""
    # Din løsning her
    pass

## TESTS ##
assert kvadrat(3) == 9,  "kvadrat(3) skal være 9"
assert kvadrat(-2) == 4, "kvadrat(-2) skal være 4"
```
````

Teksten etter kommaet i en `assert` er meldingen når testen mislykkes. Skriv den som om du snakket med studentene.

Slik ser oppgaven ut, prøv den med en gang:

```{py-exercise}
#| label: check-kvadrat
def kvadrat(x):
    """Returner kvadratet av x."""
    # Din løsning her
    pass

## TESTS ##
assert kvadrat(3) == 9,  "kvadrat(3) skal være 9"
assert kvadrat(-2) == 4, "kvadrat(-2) skal være 4"
```

---

## 4 – Skrive en matteoppgave

I `math-exercise` står det riktige svaret i oppgaveteksten, i hakeparenteser etter en understrek:

````markdown
```{math-exercise}
#| label: sirkelareal
#| vars: r
En sirkel har radius $r = 3$. Oppgi arealet eksakt (skriv pi for π):

$A =$ _[pi*9]
```
````

`#| vars:` angir symbolene som kan forekomme i svaret. Svaret i `[...]` er et SymPy-uttrykk. Prøv: `pi*9`, `9*pi` og `3**2*pi` teller alle som riktig.

```{math-exercise}
#| label: check-sirkelareal
#| vars: r
En sirkel har radius $r = 3$. Oppgi arealet eksakt (skriv pi for π):

$A =$ _[pi*9]
```

---

## 5 – Se resultatet

Skriv `quarto preview` i terminalen. Ved første klikk på **Kjør koden** eller **Kontroller** lastes Python, og det tar noen sekunder. Deretter viser oppgavene:

- for `py-exercise` en editor med knapper for å kjøre og tilbakestille. Etter kjøringen står det hvilke tester som bestod, og hvilken melding som vises ved en feil.
- for `math-exercise` et inndatafelt og en knapp **Kontroller** som skriver resultatet ved siden av feltet.

Gjør en feil med vilje og se om meldingen hjelper studentene videre. Prøv også den riktige løsningen.

---

## 6 – Hjelp fra en KI (frivillig)

Hver oppgave kan få en knapp **Tilbakemelding**. Den gjør oppgaven og det gjeldende svaret om til en ferdig tekst som studentene limer inn i en KI etter eget valg. For `py-exercise` slår du det på og angir oppdraget i hver oppgave:

````markdown
---
py-exercise:
  feedback: true
---

```{py-exercise}
#| task: Fullfør kvadrat slik at den returnerer kvadratet av x.
def kvadrat(x):
    pass

## TESTS ##
assert kvadrat(3) == 9
```
````

Testene og den forventede løsningen sendes aldri. Hvordan du stiller inn hintnivåer og bygger en side helt uten KI, står på siden [KI-tilbakemelding og lagring](../../../exp/Qmd Files/Tipps and Tricks/exp_ext_feedback.html).

---

## 7 – Svarene bevares

Det studentene skriver inn, blir i nettleseren på enheten deres. Neste gang de besøker siden, er det der igjen. Ingenting går til noen server. Studentene kan slå det av i innstillingsdialogen, eksportere svarene sine eller slette dem.

En opgave med automatisk kontrol fortæller med det samme de studerende, om deres løsning er rigtig. Du skriver opgaven og det rigtige svar én gang, og kontrollen kører i browseren. Der findes to slags:

| Opgave | De studerende | Kontrolleres |
|---|---|---|
| `py-exercise` | fuldfører en Python-funktion | med skjulte test (`assert`) |
| `math-exercise` | skriver et matematisk svar | med SymPy, ligeværdige skrivemåder tæller |

::: {.callout-warning}
## Interaktivt kun i HTML
Kontrollen virker kun i **HTML-output**, altså i websteder (`format: html`) og bøger. I PDF eller Word vises kun opgavens tekst.
:::
