Die YML-Datei

Die Datei _quarto.yml ist die Schaltzentrale deines Quarto-Projekts. Was du hier einstellst, gilt für das ganze Projekt, solange es nicht in einer einzelnen .qmd-Datei oder in einem Profil überschrieben wird.

HinweisOffizielle Referenz

quarto.org/docs/reference/projects/websites

Ausgabeformate

Quarto kann dieselbe Quelle in mehrere Formate zugleich bauen:

_quarto.yml
format:
  html:
    toc: true
    theme: cosmo
  pdf:
    toc: true
    documentclass: article
  docx:
    toc: true

Alle Formate bauen: quarto render Ein Format bauen: quarto render --to pdf

Tipp

Jede Format-Option lässt sich je Seite im Kopf der .qmd-Datei überschreiben.

Ausführen und freeze

_quarto.yml
execute:
  echo: true        # Quellcode zeigen
  eval: true        # Code ausführen
  warning: false    # Warnungen unterdrücken
  freeze: auto      # nur neu ausführen, wenn sich die Quelle ändert
Wert von freeze Verhalten
false immer neu ausführen
true nie neu ausführen, gespeicherte Ausgabe benutzen
auto nur neu ausführen, wenn sich die .qmd-Datei ändert

Die gespeicherten Ergebnisse liegen in _freeze/. Nimm den Ordner mit ins Git-Repository, dann müssen andere nicht alles neu ausführen.

Warnung

freeze: auto achtet auf die .qmd-Datei, nicht auf deine Datendateien. Wenn du eine CSV-Datei änderst, aber nicht die .qmd, lösche den passenden Ordner in _freeze/, um einen neuen Lauf zu erzwingen.

Profile

Mit Profilen pflegst du mehrere Bauvarianten eines Projekts, für verschiedene Zielgruppen, Sprachen oder Formate.

_quarto.yml
profile:
  default: web
  group:
    - [web, print]

Aus einer Gruppe ist immer genau ein Profil aktiv. Jedes Profil hat eine eigene Datei _quarto-<name>.yml, die die Grundeinstellungen überschreibt oder ergänzt:

_quarto-print.yml
project:
  output-dir: docs/print
format:
  pdf:
    toc: true

Ein bestimmtes Profil bauen:

quarto render --profile print
Tipp

Dieses Tutorial hat zwei Gruppen von Profilen: das Niveau (beg, int, exp) und die Sprache (deutsch, english, svenska, norsk, dansk). Bei jedem Lauf ist aus jeder Gruppe eines aktiv, z. B. quarto render --profile int,english. Mehr dazu unter Mehrsprachige Projekte.

Seitenleiste

Grundaufbau

_quarto.yml
website:
  sidebar:
    - id: my-sidebar
      style: docked       # docked | floating
      collapse-level: 1   # wie viele Ebenen anfangs ausgeklappt sind
      contents:
        - href: page.qmd
          text: "Titel der Seite"

Abschnitte, die sich einklappen lassen

Mit section: legst du Gruppen an, die sich in der Seitenleiste einklappen lassen. Ein Abschnitt kann eine eigene Übersichtsseite haben (href) oder nur eine Beschriftung sein:

contents:
  - section: "Kapitel 1"          # nur Beschriftung, keine Seite
    contents:
      - href: ch1/part1.qmd
        text: Teil 1

  - section: "Kapitel 2"
    href: ch2/index.qmd           # ein Klick auf den Titel öffnet diese Seite
    contents:
      - href: ch2/part1.qmd
        text: Teil 1

Ebenen ausklappen

collapse-level legt fest, wie viele Ebenen beim Laden der Seite ausgeklappt sind:

Wert Wirkung
1 nur die oberste Ebene ist zu sehen, alle Abschnitte sind eingeklappt
2 die Abschnitte der ersten Ebene sind ausgeklappt (Standard)
3 auch die Abschnitte der zweiten Ebene sind ausgeklappt 
sidebar:
  collapse-level: 1   # eingeklappt beginnen, Leser klappen auf, was sie brauchen

Feste oder schwebende Seitenleiste

style: docked zeigt die Seitenleiste als feste Spalte mit eigenem Hintergrund. style: floating stellt sie ohne Hintergrund neben den Text:

website:
  sidebar:
    style: floating

Auf einer einzelnen Seite blendest du die Seitenleiste im Kopf der .qmd-Datei aus:

seite.qmd
---
sidebar: false

Ein Theme wählen

Quarto benutzt für HTML die Themes von Bootswatch:

_quarto.yml
format:
  html:
    theme: cosmo

Beliebte Themes: default, cosmo, flatly, lumen, minty, sandstone, simplex, slate (dunkel), solar (dunkel), superhero (dunkel).

Umschalter hell/dunkel

_quarto.yml
format:
  html:
    theme:
      light: flatly
      dark: darkly

Quarto setzt von selbst einen Umschalter in die Navigationsleiste.

Eigenes CSS auf ein Theme setzen

_quarto.yml
format:
  html:
    theme:
      - cosmo
      - custom.scss

Lege custom.scss neben die _quarto.yml:

custom.scss
/*-- scss:defaults --*/
/* Bootstrap-Variablen überschreiben */
$primary: #0d6efd;
$font-size-base: 1rem;
$headings-font-weight: 600;

/*-- scss:rules --*/
/* gewöhnliche CSS-Regeln */
h2 {
  border-bottom: 2px solid $primary;
  padding-bottom: 0.25rem;
}

Die beiden Abschnittsmarken verlangt Quarto:

Abschnitt Zweck
/*-- scss:defaults --*/ SCSS-Variablen von Bootstrap überschreiben
/*-- scss:rules --*/ gewöhnliche CSS-Regeln schreiben

Wichtige SCSS-Variablen

/*-- scss:defaults --*/
$primary:             #0d6efd;
$body-bg:             #ffffff;
$body-color:          #212529;
$font-family-base:    "Inter", sans-serif;
$font-size-base:      1rem;
$headings-font-weight: 600;
$border-radius:       0.375rem;

Regeln nur für den dunklen Modus

custom.scss
/*-- scss:rules --*/
[data-bs-theme="dark"] .my-box {
  background-color: #1e1e2e;
}

Eigenes Symbol in einem Callout, ein Beispiel für CSS

Ein Callout bekommt ein ganz eigenes Symbol, wenn du eine eigene CSS-Klasse mit ein paar Regeln verbindest.

Der Kasten hier ist das Ergebnis. Das Symbol 🎨 kommt vollständig aus dem CSS:

TippEigenes Symbol über CSS

Dieser Callout hat die Klasse .palette-callout. Das Symbol 🎨 wird mit ::before eingefügt, das übliche SVG wird mit display: none ausgeblendet.

Der Code dazu:

::: {.callout-tip .palette-callout}
## Eigenes Symbol über CSS
Inhalt.
:::
custom.scss
/*-- scss:rules --*/
.palette-callout > .callout-header .callout-icon-container::before {
  content: "🎨";
  font-size: 1.1rem;
  margin-right: 0.4rem;
}
.palette-callout > .callout-header .callout-icon-container svg {
  display: none;
}
TippSehr nützlich: mit F12 nachsehen

Bevor du einen Stil ändern kannst, musst du wissen, welche CSS-Klasse gemeint ist.

① Öffne die gebaute HTML-Seite im Browser.

② Drücke F12, klicke auf das Zeiger-Symbol und fahre über das Element, das du gestalten willst.

③ Im HTML-Bereich siehst du das Element und seine Klassen:

<h2 class="anchored" id="my-section">My Section</h2>

④ Im Bereich „Styles“ siehst du, welche CSS-Regeln gelten und aus welcher Datei sie kommen.

⑤ Klicke auf einen Wert, um ihn direkt zu ändern. Die Seite zeigt es sofort, du kannst also ausprobieren, bevor du Code schreibst.

Hinweis Symbole gehen auch in Callout-Titeln

Eigene Symbole aus Theme/Icons/ erscheinen überall, wo Quarto HTML im Text annimmt, auch in Callout-Titeln. Das <i class="python"></i> oben entsteht allein durch diese CSS-Regel in der SCSS-Datei:

i.python {
  content: url("Theme/Icons/python.svg");
  display: inline-block;
  height: 1em;
  width: 1em;
  margin-right: 0.25em;
}

## Output formats

Quarto can render the same source to multiple formats at once:

```{.yaml filename="_quarto.yml"}
format:
  html:
    toc: true
    theme: cosmo
  pdf:
    toc: true
    documentclass: article
  docx:
    toc: true
```

Run all formats: `quarto render`
Run one format: `quarto render --to pdf`

::: {.callout-tip}
Any format option can be overridden per page in the header of the `.qmd` file.
:::

## Execute & freeze

```{.yaml filename="_quarto.yml"}
execute:
  echo: true        # show source code
  eval: true        # run the code
  warning: false    # suppress warnings
  freeze: auto      # re-run only when source changes
```

| `freeze` value | Behaviour |
|---|---|
| `false` | Always re-execute |
| `true` | Never re-execute, use cached output |
| `auto` | Re-execute only when the `.qmd` file changes |

Frozen results are stored in `_freeze/`. Commit this folder so collaborators don't need to re-run everything.

::: {.callout-warning}
`freeze: auto` watches the `.qmd` file, not your data files.
If you update a CSV but not the `.qmd`, delete the matching folder in `_freeze/` to force a re-run.
:::

## Profiles

Profiles let you maintain multiple build variants of one project, for different audiences, languages, or formats.

```{.yaml filename="_quarto.yml"}
profile:
  default: web
  group:
    - [web, print]
```

Exactly one profile of a group is active at a time. Each profile has its own config file `_quarto-<name>.yml` that overrides or extends the root config:

```{.yaml filename="_quarto-print.yml"}
project:
  output-dir: docs/print
format:
  pdf:
    toc: true
```

Render a specific profile:

```{.bash}
quarto render --profile print
```

::: {.callout-tip}
This tutorial has **two groups** of profiles: the level (`beg`, `int`, `exp`) and the language (`deutsch`, `english`, `svenska`, `norsk`, `dansk`). Every run has one of each group active, e.g. `quarto render --profile int,english`. More on this in [Multilanguage Projects](exp_multilanguage.qmd).
:::

## Sidebar {#sidebar}

### Basic setup

```{.yaml filename="_quarto.yml"}
website:
  sidebar:
    - id: my-sidebar
      style: docked       # docked | floating
      collapse-level: 1   # how many levels are expanded by default
      contents:
        - href: page.qmd
          text: "Page Title"
```

### Sections: collapsible groups

Use `section:` to create collapsible groups in the sidebar.
A section can have its own overview page (`href`) or just be a label:

```{.yaml}
contents:
  - section: "Chapter 1"          # label only, no page
    contents:
      - href: ch1/part1.qmd
        text: Part 1

  - section: "Chapter 2"
    href: ch2/index.qmd           # clicking the section title opens this page
    contents:
      - href: ch2/part1.qmd
        text: Part 1
```

### Collapse level

`collapse-level` controls how many nesting levels are **expanded** when the page loads:

| Value | Effect |
|---|---|
| `1` | Only top-level items visible, all sections collapsed |
| `2` | First-level sections expanded (default) |
| `3` | Second-level sections expanded as well |

```{.yaml}
sidebar:
  collapse-level: 1   # start collapsed, readers expand what they need
```

### Docked or floating sidebar

`style: docked` shows the sidebar as a fixed column with its own background. `style: floating` places it next to the text without a background:

```{.yaml}
website:
  sidebar:
    style: floating
```

To hide the sidebar on a single page, use the header of that `.qmd` file:

```{.yaml filename="page.qmd"}
---
sidebar: false
---
```

## Styles & CSS {#styles--css}

### Choosing a theme

Quarto uses [Bootswatch](https://bootswatch.com/) themes for HTML output:

```{.yaml filename="_quarto.yml"}
format:
  html:
    theme: cosmo
```

Popular themes: `default`, `cosmo`, `flatly`, `lumen`, `minty`, `sandstone`, `simplex`, `slate` (dark), `solar` (dark), `superhero` (dark).

### Light / dark toggle

```{.yaml filename="_quarto.yml"}
format:
  html:
    theme:
      light: flatly
      dark: darkly
```

Quarto adds a toggle button to the navbar automatically.

### Adding custom CSS on top of a theme

```{.yaml filename="_quarto.yml"}
format:
  html:
    theme:
      - cosmo
      - custom.scss
```

Create `custom.scss` next to `_quarto.yml`:

```{.scss filename="custom.scss"}
/*-- scss:defaults --*/
/* Override Bootstrap design tokens */
$primary: #0d6efd;
$font-size-base: 1rem;
$headings-font-weight: 600;

/*-- scss:rules --*/
/* Regular CSS rules */
h2 {
  border-bottom: 2px solid $primary;
  padding-bottom: 0.25rem;
}
```

The two section markers are required by Quarto:

| Section | Purpose |
|---|---|
| `/*-- scss:defaults --*/` | Override Bootstrap SCSS variables |
| `/*-- scss:rules --*/` | Write plain CSS rules |

### Key SCSS variables

```{.scss}
/*-- scss:defaults --*/
$primary:             #0d6efd;
```

## Sidepanel {#sidebar}

### Grundopsætning

```{.yaml filename="_quarto.yml"}
website:
  sidebar:
    - id: my-sidebar
      style: docked       # docked | floating
      collapse-level: 1   # how many levels are expanded by default
      contents:
        - href: page.qmd
          text: "Page Title"
```

### Afsnit: grupper, der kan foldes sammen

Brug `section:` til at lave grupper i sidepanelet, der kan foldes sammen.
Et afsnit kan have sin egen oversigtsside (`href`) eller bare være en etiket:

```{.yaml}
contents:
  - section: "Chapter 1"          # label only, no page
    contents:
      - href: ch1/part1.qmd
        text: Part 1

  - section: "Chapter 2"
    href: ch2/index.qmd           # clicking the section title opens this page
    contents:
      - href: ch2/part1.qmd
        text: Part 1
```

### Sammenfoldningsniveau

`collapse-level` styrer, hvor mange niveauer der er **foldet ud**, når siden indlæses:

| Værdi | Effekt |
|---|---|
| `1` | Kun det øverste niveau vises, alle afsnit er foldet sammen |
| `2` | Afsnit på første niveau er foldet ud (standard) |
| `3` | Også afsnit på andet niveau er foldet ud |

```{.yaml}
sidebar:
  collapse-level: 1   # start collapsed, readers expand what they need
```

### Fastgjort eller flydende sidepanel

`style: docked` viser sidepanelet som en fast kolonne med sin egen baggrund. `style: floating` lægger det ved siden af teksten uden baggrund:

```{.yaml}
website:
  sidebar:
    style: floating
```

For at skjule sidepanelet på en enkelt side bruger du hovedet i den `.qmd`-fil:

```{.yaml filename="page.qmd"}
---
sidebar: false
---
```


### Hopfällningsnivå

`collapse-level` styr hur många nivåer som är **utfällda** när sidan laddas:

| Värde | Effekt |
|---|---|
| `1` | Bara översta nivån syns, alla avsnitt är hopfällda |
| `2` | Avsnitt på första nivån är utfällda (standard) |
| `3` | Även avsnitt på andra nivån är utfällda |

```{.yaml}
sidebar:
  collapse-level: 1   # start collapsed, readers expand what they need
```

### Dockat eller flytande sidofält

`style: docked` visar sidofältet som en fast kolumn med egen bakgrund. `style: floating` lägger det bredvid texten utan bakgrund:

```{.yaml}
website:
  sidebar:
    style: floating
```

För att dölja sidofältet på en enskild sida använder du huvudet i den `.qmd`-filen:

```{.yaml filename="page.qmd"}
---
sidebar: false
---
```

## Stilar & CSS {#styles--css}

### Välja tema

Quarto använder teman från [Bootswatch](https://bootswatch.com/) för HTML:

```{.yaml filename="_quarto.yml"}
format:
  html:
    theme: cosmo
```

Populära teman: `default`, `cosmo`, `flatly`, `lumen`, `minty`, `sandstone`, `simplex`, `slate` (mörkt), `solar` (mörkt), `superhero` (mörkt).

### Växla mellan ljust och mörkt

```{.yaml filename="_quarto.yml"}
format:
  html:
    theme:
      light: flatly
      dark: darkly
```

Quarto lägger automatiskt till en växlingsknapp i menyraden.

### Egen CSS ovanpå ett tema

```{.yaml filename="_quarto.yml"}
format:
  html:
    theme:
      - cosmo
      - custom.scss
```

Skapa `custom.scss` bredvid `_quarto.yml`:

```{.scss filename="custom.scss"}
/*-- scss:defaults --*/
/* Override Bootstrap design tokens */
$primary: #0d6efd;
$font-size-base: 1rem;
$headings-font-weight: 600;

/*-- scss:rules --*/
/* Regular CSS rules */
h2 {
  border-bottom: 2px solid $primary;
  padding-bottom: 0.25rem;
}
```

Quarto kräver de två avsnittsmarkeringarna:

| Avsnitt | Syfte |
|---|---|
| `/*-- scss:defaults --*/` | Ändra Bootstraps SCSS-variabler |
| `/*-- scss:rules --*/` | Skriva vanliga CSS-regler |

### Viktiga SCSS-variabler

```{.scss}
/*-- scss:defaults --*/
$primary:             #0d6efd;
$body-bg:             #ffffff;
$body-color:          #212529;
$font-family-base:    "Inter", sans-serif;
$font-size-base:      1rem;
$headings-font-weight: 600;
$border-radius:       0.375rem;
```

### Regler för mörkt läge

```{.scss filename="custom.scss"}
/*-- scss:rules --*/
[data-bs-theme="dark"] .my-box {
  background-color: #1e1e2e;
}
```

### Egen ikon i en inforuta, ett praktiskt CSS-exempel

En inforuta kan få en helt egen ikon genom att kombinera en egen CSS-klass med några regler.

Inforutan nedanför **är** det färdiga resultatet. Ikonen 🎨 läggs till helt med CSS:

::: {.callout-tip .palette-callout}
## Egen ikon med CSS
Den här inforutan använder klassen `.palette-callout`. Ikonen 🎨 läggs in med `::before`, och standardikonen (SVG) döljs med `display: none`.
:::

Koden som ger detta:

````{.markdown}
::: {.callout-tip .palette-callout}
## Custom icon via CSS
Content here.
:::
````

```{.scss filename="custom.scss"}
/*-- scss:rules --*/
.palette-callout > .callout-header .callout-icon-container::before {
  content: "🎨";
  font-size: 1.1rem;
  margin-right: 0.4rem;
}
.palette-callout > .callout-header .callout-icon-container svg {
  display: none;
}
```

::: {.callout-tip collapse="true"}
## Mycket bra att känna till: inspektera med F12

Innan du kan ändra en stil måste du veta vilken CSS-klass du ska rikta in dig på.

**① Öppna den renderade HTML-sidan i en webbläsare.**

**② Tryck på `F12`**, klicka på pilsymbolen och håll muspekaren över det element du vill formge.

**③ I HTML-panelen** ser du elementet och dess klasser:

```{.html}
<h2 class="anchored" id="my-section">My Section</h2>
```

**④ I panelen Styles** ser du vilka CSS-regler som gäller och från vilken stilmall de kommer.

**⑤ Klicka på ett värde för att ändra det direkt.** Sidan uppdateras genast, så du kan experimentera innan du skriver någon kod.
:::

## <i class="python"></i> Ikoner fungerar också i inforutors rubriker

Egna ikoner från `Theme/Icons/` visas överallt där Quarto accepterar HTML i texten, även i inforutors rubriker. `<i class="python"></i>` ovanför skapas helt av den här CSS-regeln i SCSS-filen:

```{.scss}
i.python {
  content: url("Theme/Icons/python.svg");
  display: inline-block;
  height: 1em;
  width: 1em;
  margin-right: 0.25em;
}
```
