Lag en bok

1 – Åpne en ny mappe i VS Code

Lag en ny tom mappe (for eksempel min-bok) og åpne den i VS Code via File → Open Folder. Klikk på Yes, I trust the authors hvis dialogboksen kommer opp.

2 – Lag et bokprosjekt

① Lag et nytt Quarto-prosjekt

Gå til File → New File…. Det kommer en liten meny, velg Quarto Project.

Velg Book Project og deretter prosjektmappen din.

② Bokfilene dine er klare

Quarto har laget hele bokstrukturen:

  • _quarto.yml: innstillingene for boken og rekkefølgen på kapitlene
  • index.qmd: forside eller forord
  • intro.qmd, summary.qmd: eksempelkapitler
  • references.bib: litteraturfil
  • references.qmd: side med litteraturlisten

3 – Forhåndsvis boken

① Kjør quarto preview i terminalen

Åpne terminalen (View → Terminal) og kjør:

quarto preview

Boken bygges, og en forhåndsvisning åpnes i VS Code og i nettleseren.

② Se resultatet i nettleseren

Boken åpnes i nettleseren med:

  • et sidefelt til venstre med alle kapitlene
  • lenker til forrige og neste kapittel nederst på hver side
  • en innholdsfortegnelse til høyre for det gjeldende kapittelet

4 – Legg til og endre kapitler

Åpne _quarto.yml for å bestemme hvilke filer som er kapitler, og i hvilken rekkefølge:

book:
  title: "My Lecture Notes"
  author: "Your Name"
  chapters:
    - index.qmd
    - intro.qmd
    - summary.qmd
    - references.qmd

Hver oppføring er filnavnet til en .qmd-fil i mappen. Legg til en linje for et nytt kapittel, og lag den tilhørende .qmd-filen.

Tips✅ Boken din kjører!
  • Endre en kapittelfil og lagre, så oppdateres forhåndsvisningen med en gang
  • Klar til å publisere? Se Publiser nettstedet →. Mappen _book fungerer akkurat som mappen _site

## 1 – Einen neuen Ordner in VS Code öffnen

Lege einen neuen, leeren Ordner an (zum Beispiel `my-book`) und öffne ihn in VS Code über **File → Open Folder**.
Klicke auf **Yes, I trust the authors**, falls das Fenster erscheint.

---

## 2 – Ein Buchprojekt anlegen

**① Neues Quarto-Projekt anlegen**

![](../../Img Files/Getting Started/create_new_file_menu.png)

Gehe auf **File → New File…**. Es erscheint ein kleines Menü, wähle dort **Quarto Project**.

![](../../Img Files/Getting Started/quarto_project_choice.png)

Wähle **Book Project** und dann deinen Projektordner.

---

**② Die Dateien deines Buchs sind da**

![](../../Img Files/Getting Started/quarto_book_project_files.png)

Quarto hat den ganzen Aufbau des Buchs angelegt:

- `_quarto.yml`: Einstellungen des Buchs und Reihenfolge der Kapitel
- `index.qmd`: Titelseite bzw. Vorwort
- `intro.qmd`, `summary.qmd`: Beispielkapitel
- `references.bib`: Literaturdatei
- `references.qmd`: Seite mit dem Literaturverzeichnis

---

## 3 – Vorschau des Buchs

**① `quarto preview` im Terminal ausführen**

![](../../Img Files/Getting Started/book_preview_bottin_in_vscode.png)

Öffne das Terminal (**View → Terminal**) und gib ein:

```
quarto preview
```

Das Buch wird gebaut, und eine Vorschau öffnet sich in VS Code und im Browser.

---

**② Das Ergebnis im Browser ansehen**

![](../../Img Files/Getting Started/book_with_terminal_quartopreview.png)

Dein Buch öffnet sich im Browser mit:

- einer **Leiste links**, die alle Kapitel auflistet
- **Zurück / Weiter** am Ende jeder Seite
- einem **Inhaltsverzeichnis** rechts für das aktuelle Kapitel

---

## 4 – Kapitel hinzufügen und ändern

In der `_quarto.yml` legst du fest, welche Dateien Kapitel sind und in welcher Reihenfolge:

```yaml
book:
  title: "Mein Vorlesungsskript"
  author: "Dein Name"
  chapters:
    - index.qmd
    - intro.qmd
    - summary.qmd
    - references.qmd
```

Jeder Eintrag ist der Dateiname einer `.qmd`-Datei in deinem Ordner.
Für ein neues Kapitel ergänzt du eine Zeile und legst die passende `.qmd`-Datei daneben an.

---

::: {.callout-tip}
## ✅ Dein Buch läuft!

- Ändere die `.qmd`-Datei eines Kapitels und speichere, die Vorschau zeigt es sofort
- Bereit zum Veröffentlichen? Siehe [Website veröffentlichen →](beg_website_3.qmd). Der Ordner `_book` funktioniert genau wie der Ordner `_site`
:::
::::

## 1 — Open a new folder in VS Code

Create a new empty folder (e.g. `my-book`) and open it in VS Code via **File → Open Folder**.
Click **Yes, I trust the authors** if the dialog appears.

---

## 2 — Create a Book project

**① Create a new Quarto project**

![](../../Img Files/Getting Started/create_new_file_menu.png)

Go to **File → New File…**. A small menu appears — select **Quarto Project**.

![](../../Img Files/Getting Started/quarto_project_choice.png)

Select **Book Project** and choose your project folder.

---

**② Your book files are ready**

![](../../Img Files/Getting Started/quarto_book_project_files.png)

Quarto created the full book structure:

- `_quarto.yml` — book settings and chapter order
- `index.qmd` — cover / preface
- `intro.qmd`, `summary.qmd` — example chapters
- `references.bib` — bibliography file
- `references.qmd` — references page

---

## 3 — Preview your book

**① Run quarto preview in the terminal**

![](../../Img Files/Getting Started/book_preview_bottin_in_vscode.png)

Open the terminal (**View → Terminal**) and run:

```
quarto preview
```

The book builds and a live preview opens in VS Code and in your browser.

---

**② See the result in your browser**

![](../../Img Files/Getting Started/book_with_terminal_quartopreview.png)

Your book opens in the browser with:

- A **left sidebar** listing all chapters
- **Previous / Next** navigation at the bottom of each page
- A **table of contents** on the right for the current chapter

---

## 4 — Add and edit chapters

Open `_quarto.yml` to control which files are chapters and in what order:

```yaml
book:
  title: "My Lecture Notes"
  author: "Your Name"
  chapters:
    - index.qmd
    - intro.qmd
    - summary.qmd
    - references.qmd
```

Each entry is the filename of a `.qmd` file in your folder.
Add a new line to add a new chapter — create the matching `.qmd` file alongside it.

---

::: {.callout-tip}
## ✅ Your book is running!

- Edit any chapter `.qmd` file and save — the preview updates instantly
- Ready to publish? See [Publish your Website →](beg_website_3.qmd) — the `_book` folder works exactly like the `_site` folder
:::
