Lag et oppgaveark

1 – Lag en ny Quarto-fil

① Åpne dialogen New File

Gå i VS Code til File → New File…. Det kommer en liten meny. Velg Quarto Document.

② Filen åpnes med et ferdig hode

VS Code lager en ny fil der en enkel innstillingsblokk allerede er fylt ut. Lagre den med et navn som exercises.qmd (File → Save eller Ctrl+S).

2 – Angi utdataformat

① Endre hodet

Toppen av filen styrer utdataformatet. Endre den til:

---
title: "Exercise Sheet 1"
author: "Your Name"
format: pdf
---

Dette sier til Quarto: lag en PDF med denne tittelen og forfatteren.

Note

PDF krever TinyTeX, se Dette trenger du hvis du ikke har installert det ennå. For HTML endrer du format: pdf til format: html, da trengs ingen ekstra verktøy.

3 – Skriv oppgavene dine

Under hodet skriver du innholdet som vanlig tekst. Bruk ## til overskrifter. La det stå en tom linje mellom avsnittene.

## Exercise 1

Calculate the derivative of $f(x) = x^2 + 3x$.

## Exercise 2

Explain the difference between a list and a dictionary in Python.

4 – Legg til et kodeeksempel (valgfritt)

Slik viser du Python-kode som vises, men ikke kjøres:

```python
x = [1, 2, 3, 4]
print(sum(x))
```

5 – Rendre arket

Åpne terminalen via View → Terminal og kjør:

Terminal
quarto render exercises.qmd

Quarto lager utdatafilen (PDF eller HTML) i samme mappe. Åpne den fra filutforskeren.

Note🔍 Forhåndsvis mens du skriver

I stedet for quarto render kan du bruke:

Terminal
quarto preview exercises.qmd

Da åpnes en forhåndsvisning i nettleseren som oppdateres hver gang du lagrer filen.

Tips✅ Oppgavearket ditt er ferdig!
  • Vil du eksportere som HTML, Word eller PDF fra samme fil? Se Andre utdataformater →
  • Vil du at studentene skal kjøre og endre Python-kode i nettleseren? Se Interaktiv kode →

## 1 – Eine neue Quarto-Datei anlegen

**① Das Fenster „New File“ öffnen**

![](../../Img Files/Getting Started/create_new_file_menu.png)

Gehe in VS Code auf **File → New File…**.
Es erscheint ein kleines Menü. Wähle **Quarto Document**.

---

**② Die Datei öffnet sich mit einem fertigen Kopf**

![](../../Img Files/Getting Started/Screenshot 2026-03-27 102111.png)

VS Code legt eine neue Datei an, in der ein einfacher Einstellungsblock schon ausgefüllt ist.
Speichere sie unter einem Namen wie `exercises.qmd` (**File → Save** oder `Strg+S`).

---

## 2 – Das Ausgabeformat festlegen

**① Den Kopf der Datei ändern**

Der Anfang der Datei bestimmt das Ausgabeformat. Ändere ihn so:

```yaml
---
title: "Übungsblatt 1"
author: "Dein Name"
format: pdf
---
```

Das sagt Quarto: Erzeuge ein PDF mit diesem Titel und diesem Namen.

::: {.callout-note}
Für PDF brauchst du TinyTeX, siehe [Was du brauchst](beg_exercise_1.qmd), falls du es noch nicht installiert hast.
Für HTML änderst du `format: pdf` in `format: html`, dann brauchst du keine weiteren Werkzeuge.
:::

---

## 3 – Die Aufgaben schreiben

Unter den Kopf schreibst du deinen Inhalt als normalen Text.
Mit `##` beginnt eine Überschrift. Zwischen Absätzen steht eine Leerzeile.

```markdown
## Aufgabe 1

Berechne die Ableitung von $f(x) = x^2 + 3x$.

## Aufgabe 2

Erkläre den Unterschied zwischen einer Liste und einem Dictionary in Python.
```

---

## 4 – Ein Code-Beispiel einfügen (wenn du möchtest)

So zeigst du Python-Code, der angezeigt, aber nicht ausgeführt wird:

````markdown
```python
x = [1, 2, 3, 4]
print(sum(x))
```
````

---

## 5 – Das Blatt bauen

Öffne das **Terminal** über **View → Terminal** und gib ein:

```{.bash filename="Terminal"}
quarto render exercises.qmd
```

![](../../Img Files/Getting Started/terminal_quarto_render.png)

Quarto legt die Ausgabedatei (PDF oder HTML) im selben Ordner ab. Öffne sie aus dem Datei-Explorer.

::: {.callout-note collapse="true"}
## 🔍 Vorschau beim Schreiben

Statt `quarto render` kannst du auch das hier benutzen:

```{.bash filename="Terminal"}
quarto preview exercises.qmd
```

Das öffnet im Browser eine Vorschau, die sich bei jedem Speichern der Datei aktualisiert.
:::

---

::: {.callout-tip}
## ✅ Dein Übungsblatt ist fertig!

- Aus derselben Datei HTML, Word oder PDF erzeugen? Siehe [Andere Ausgabeformate →](beg_exercise_3.qmd)
- Sollen Studierende Python-Code im Browser ausführen und verändern? Siehe [Interaktiver Code →](beg_extensions.qmd)
:::

## 1 — Create a new Quarto file

**① Open the New File dialog**

![](../../Img Files/Getting Started/create_new_file_menu.png)

In VS Code go to **File → New File…**.
A small menu appears. Select **Quarto Document**.

---

**② Your file opens with an existing header**

![](../../Img Files/Getting Started/Screenshot 2026-03-27 102111.png)

VS Code creates a new file with a basic settings block already filled in.
Save it with a name like `exercises.qmd` (**File → Save** or `Ctrl+S`).

---

## 2 — Set the output format

**① Edit the header block**

The top of the file controls the output format. Change it to:

```yaml
---
title: "Exercise Sheet 1"
author: "Your Name"
format: pdf
---
```

This tells Quarto: create a PDF with this title and author name.

::: {.callout-note}
PDF output requires TinyTeX — see [What you need](beg_exercise_1.qmd) if you have not installed it yet.
For HTML output, change `format: pdf` to `format: html` and no extra tools are needed.
:::

---

## 3 — Write your exercises

Below the header block, write your content using normal text.
Use `##` for section headings. Leave a blank line between paragraphs.

```markdown
## Exercise 1

Calculate the derivative of $f(x) = x^2 + 3x$.

## Exercise 2

Explain the difference between a list and a dictionary in Python.
```

---

## 4 — Add a code example (optional)

To show Python code that is displayed but not executed:

````markdown
```python
x = [1, 2, 3, 4]
print(sum(x))
```
````

---

## 5 — Render your sheet

Open the **Terminal** via **View → Terminal** and run:

```{.bash filename="Terminal"}
quarto render exercises.qmd
```

![](../../Img Files/Getting Started/terminal_quarto_render.png)

Quarto creates the output file (PDF or HTML) in the same folder. Open it from your file explorer.

::: {.callout-note collapse="true"}
## 🔍 Preview while writing

Instead of `quarto render`, you can use:

```{.bash filename="Terminal"}
quarto preview exercises.qmd
```

This opens a live preview in your browser that updates every time you save the file.
:::

---

::: {.callout-tip}
## ✅ Your exercise sheet is ready!

- Want to export as HTML, Word, or PDF from the same file? See [Other Output Formats →](beg_exercise_3.qmd)
- Want students to run and edit Python code in the browser? See [Interactive Code →](beg_extensions.qmd)
:::
