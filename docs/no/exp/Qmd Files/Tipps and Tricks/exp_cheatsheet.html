Cheatsheet

En hurtigreferanse for alt som tas opp i denne delen.

YAML: innstillinger i _quarto.yml

Prosjekt

project:
  type: website       # website | book | manuscript | default
  output-dir: docs    # where rendered files go

Execute (globale standardverdier for kode)

execute:
  echo: true          # show source code
  eval: true          # run the code
  warning: false      # hide warnings
  error: false        # stop on errors
  freeze: auto        # auto | true | false

Format

format:
  html:
    toc: true
    toc-depth: 3
    theme:              # one name (theme: cosmo) or a list
      - cosmo
      - custom.scss
    code-fold: true
    code-tools: true
    number-sections: false
  pdf:
    toc: true
    documentclass: article
    geometry: margin=2.5cm
  docx:
    toc: true

Nettsted

website:
  title: "My Site"
  navbar:
    left:
      - text: "Home"
        href: index.qmd
      - text: "External"
        href: https://example.com
    right:
      - icon: github
        href: https://github.com/your/repo
  sidebar:
    - id: my-sidebar
      style: docked        # docked | floating
      contents:
        - href: page.qmd
          text: Page Title
        - section: "Group"
          contents:
            - href: sub.qmd
              text: Sub-page

Profiler

profile:
  default: [web, deutsch]
  group:
    - [web, print]          # exactly one of each group is active
    - [deutsch, english]
quarto render --profile print,english

py-exercise

```{py-exercise}
#| caption: Title
#| forbidden-keywords: for, while
def my_func(x):
    pass        # student fills this in

## TESTS ##
assert my_func(2) == 4, "Feedback on failure"
```

math-exercise

```{math-exercise}
#| label: circle
#| vars: r
#| mode: equivalent
Area of a circle with r = 3: _[pi*9]
```
Felt Betydning
_[a] / __[a] / ___[a] smalt / middels / bredt
vec[a,b,c] vektor
mat[a,b;c,d] matrise (komma: kolonne, semikolon: rad)
mode Kontrollerer
equivalent matematisk ekvivalent (standard), med reject og form
exact nøyaktig denne skrivemåten
numeric tallverdi, med tolerance, decplaces eller sigfigs
string / string_ci tekst bokstavelig / uten hensyn til store og små bokstaver
set liste uten rekkefølge
custom din egen kontrollkode i checker

Flere innstillinger: pool: true, partial-credit: true, field-labels, context.

JSXGraph

```jsxgraph
var board = JXG.JSXGraph.initBoard(BOARDID, {
    boundingbox: [-5, 5, 5, -5], axis: true
});
board.create('functiongraph', [Math.sin]);
```

Som svar på en oppgave: en blokk med {.jsxgraph assessment_id="board"} og JXG.QuartoAssessment.register(...), og i oppgaven #| mode: custom og #| response: jsxgraph:board.

## YAML: Optionen in der `_quarto.yml`

### Projekt

```{.yaml}
project:
  type: website       # website | book | manuscript | default
  output-dir: docs    # wohin die gebauten Dateien kommen
```

### Ausführen (Vorgaben für allen Code)

```{.yaml}
execute:
  echo: true          # Quellcode zeigen
  eval: true          # Code ausführen
  warning: false      # Warnungen ausblenden
  error: false        # bei Fehlern abbrechen
  freeze: auto        # auto | true | false
```

### Format

```{.yaml}
format:
  html:
    toc: true
    toc-depth: 3
    theme:              # ein Name (theme: cosmo) oder eine Liste
      - cosmo
      - custom.scss
    code-fold: true
    code-tools: true
    number-sections: false
  pdf:
    toc: true
    documentclass: article
    geometry: margin=2.5cm
  docx:
    toc: true
```

### Website

```{.yaml}
website:
  title: "Meine Seite"
  navbar:
    left:
      - text: "Start"
        href: index.qmd
      - text: "Extern"
        href: https://example.com
    right:
      - icon: github
        href: https://github.com/your/repo
  sidebar:
    - id: my-sidebar
      style: docked        # docked | floating
      contents:
        - href: page.qmd
          text: Titel der Seite
        - section: "Gruppe"
          contents:
            - href: sub.qmd
              text: Unterseite
```

### Profile

```{.yaml}
profile:
  default: [web, deutsch]
  group:
    - [web, print]          # aus jeder Gruppe ist genau eines aktiv
    - [deutsch, english]
```

```{.bash}
quarto render --profile print,english
```

## QMD: Optionen für Codeblöcke

```{.yaml}
#| echo: false          # Quellcode ausblenden
#| eval: false          # nicht ausführen (nur Code zeigen)
```

### math-exercise

````{.markdown}
```{math-exercise}
#| label: kreis
#| vars: r
#| mode: equivalent
Flächeninhalt eines Kreises mit r = 3: _[pi*9]
```
````

| Feld | Bedeutung |
|---|---|
| `_[a]` / `__[a]` / `___[a]` | schmal / mittel / breit |
| `vec[a,b,c]` | Vektor |
| `mat[a,b;c,d]` | Matrix (Komma: Spalte, Strichpunkt: Zeile) |

| `mode` | Prüft |
|---|---|
| `equivalent` | mathematisch gleichwertig (Standard), mit `reject` und `form` |
| `exact` | genau diese Darstellung |
| `numeric` | Zahlenwert, mit `tolerance`, `decplaces` oder `sigfigs` |
| `string` / `string_ci` | Text wörtlich / ohne Groß- und Kleinschreibung |
| `set` | Liste ohne Reihenfolge |
| `custom` | eigener Prüfcode in `checker` |

Weitere Optionen: `pool: true`, `partial-credit: true`, `field-labels`, `context`.
